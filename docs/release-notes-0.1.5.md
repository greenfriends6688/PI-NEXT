# PI NEXT v0.1.5

这一版把上游 0.9.2 的功能面补齐，外观配置也收敛成了一处，同时换上新的应用图标与名称。
归档这条链路这次真正闭环了。

## 新增

- **逐模型开关**：设置 → 模型里可以按模型单独启用 / 停用，也能按服务商批量操作；
  已有选择与思考级别设置都会保留，项目级配置存在时界面明确提示当前只读。
- **刷新模型目录**：服务商发布新模型后点一下就能拿到最新列表，不用等应用更新，离线时会明确提示。
- **思考档位请求画像**：配置页逐档显示「这一档实际会发什么请求参数」，改设置时实时重算。
- **归档历史**：设置 → 归档集中列出所有已归档会话并按项目分组，可恢复或彻底删除。
- **标签页各自记会话**：刷新其中一个标签页，不会被另一个标签页最近打开的会话带走。
- **小地图增强**：悬停预览能看到每回合调了几次工具，当前回合用强调色标出。

## 改动

- **外观只剩一处**：壁纸并入「主题皮肤」卡片，皮肤编辑回到弹窗；皮肤支持浅色 / 深色两套颜色变体，
  内置壁纸直接作为卡片里的内置皮肤，点一下即生效且能继续编辑。
- **侧栏项目行**：新增「⋯」菜单（打开文件夹 / 重命名 / 从列表中移除）与「+」（在该项目下新建会话），
  「打开文件夹」调系统文件夹选择器；去掉新建任务的项目下拉与项目栏的冗余按钮。
- **新名与新图标**：界面文案、窗口标题、PWA 名称与安装包显示名统一为 PI NEXT，图标换新。
- **完整历史**仍然从导出页打开，不做应用内嵌面板。

## 修复

- **归档后会话失踪**：已归档的会话被项目分区又过滤一遍，「已归档」区永远是空的，
  点归档等于把会话藏起来；现在归档与恢复都在归档历史里闭环。
- **系统提示词面板一片空白**：旧会话读出来的提示词是空的，改为优先取运行时当前生效的那一份。
- **子代理图标被压小**：按钮固定宽度把图标挤成细条，改为按内容撑开。
- **浮窗鼠标一动就消失**：触控板的轻微抖动被当成滚动，现在这类微小移动直接忽略。
- **思考档位与实际行为对不上**：等级映射、关闭分支与预算边界现已与真实行为一致。
- **若干界面细节**：会话 / 文件面板、滚动条、扩展对话框标题换行、扩展选择项焦点环、
  登录页限流提示等一并修正。
