# PI NEXT v0.1.5-beta.3

这一版把界面外观整体重做了一遍，外加三处用户直接指定的布局调整。
全部零新依赖（不引图标库、不引组件库、不引拖拽库）。

## 新增

- **主题皮肤**：一套皮肤 = 4 个基色 + 11 个几何/材质旋钮 + 一张壁纸 + 一段自定义 CSS，
  **11 个滑块全部真的落到界面效果上**，不是只有 UI 没有效果。
  - 卡片条：横向滚动的迷你外壳缩略图（壁纸 + 玻璃块 + 强调色条），左右滚动按钮，
    底部 `新建主题 / 导入 / 编辑 / 导出`；导入自动换 id，导出成 JSON。
  - 编辑主题对话框：`主题设置 / 自定义 CSS` 两页，左侧界面预览（浅色/深色切换 +
    真·迷你外壳 + 选择壁纸 + 填充方式），右侧 4 个色值 + 11 个双列滑块，
    底部 `取消 / 恢复默认 / 保存`。
  - 皮肤只存 4 个基色，其余颜色（悬停 / 选中 / 次要文字 / 三档边框）在应用时自动派生 ——
    改一个基色整套跟着变，导出给别人时也不会出现十几个用户从没见过的色值。
  - **壁纸与主题融合**：壁纸铺满全窗，侧栏/会话列/顶栏/输入区各自半透明 + 模糊，
    会话列再叠一层阅读遮罩（正文一侧最实、边缘一侧最透）。
- **设置页新增四项**（标签与说明在左、控件在右上、行间内缩分隔线）
  - **UI 字体**：真枚举本机字体，不是只有「系统默认 / 衬线 / 等宽」三档。
  - **UI 字号**、**侧边栏半透明**、**侧边栏宽度**（直接拖动侧栏）。
- **通知设置**：开关矩阵（桌面通知 / 任务完成 / 任务失败 / 仅在窗口未聚焦时 / 通知声音）
  + `发送测试通知` / `打开系统通知设置`。开关**真接进三条投递路径**。
- **小地图悬停提示**：悬停会话轨道上的某一根刻度，显示这一回合的角色与正文预览。

## 改动

- **侧栏**：
  - 行规格统一：悬停与选中**同填充**、选中不加字重、计数徽标右对齐。
  - 行内缩统一成 10px（此前是 0 / 6 / 10 三种，行填充对不齐）。
  - 默认宽度 272 → **300**，拖拽区间 232–360。
  - 分区顺序改成 **项目 → 聊天**；新增「项目 / 聊天」左右分段切换。
  - **折叠按钮从导轨右边界移进品牌行**（原来一半压在主区顶栏上，和顶栏那排图标抢
    同一条线）；**折叠态改成三个图标的紧凑条**（展开 / 搜索 / 新建会话）。
  - 去掉「插件 / 技能」两行 —— 设置里已经有这两个分区，导轨上再来一份是重复入口。

## 修复

- **开着壁纸时侧栏与副区整块全透明**：壁纸遮罩的百分比写法在 Chrome 里不成立，
  整条背景在计算阶段失效并回落成透明。这个 bug 被「透过去看到壁纸」的表象盖住了很久，
  直到皮肤把壁纸铺满全窗才暴露。
