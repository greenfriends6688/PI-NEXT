# PI NEXT v0.1.5-beta.2

这一版是一次大批量的能力补齐：会话内查找、右栏标签概览、本地用量统计、快捷键表、
自定义命令、定时任务增强、表格与附件预览、侧栏分组排序一次到位，并修掉 5 个根因级问题。
全部零新依赖。

## 新增

- **会话内查找**：命中计数与上下条步进（Enter / Shift+Enter）并高亮；命中在未加载的历史里
  会自动把渲染窗口撑过去，命中在折叠的思考 / 工具输出里会自动展开那个块。
- **右栏标签概览**：一个浮层列出全部标签，可筛选、可批量关闭 / 关闭其他；关掉的标签能在
  「最近关闭」里一键恢复，文件标签回到原文件与原滚动位置。
- **本地用量统计**：每日热力图、模型占比、Token 趋势，区间 7 天 / 30 天 / 全部；只读本机会话文件。
- **快捷键表**：应用内快捷键的唯一列表，可录制新组合键、单行或全部恢复默认，冲突即时提示；
  侧栏、右栏、主题等快捷键都走这张表。
- **自定义命令**：管理自己的 Markdown 提示词模板，保存后斜杠面板立即可用。
- **记忆目录视图**：按文件名筛选，显示大小与修改时间，日报与恢复目录都能预览。
- **定时任务增强**：运行历史（状态 / 耗时 / 输出摘要 / 一键跳到那次会话）、错过即跳过并记录原因、
  指数退避重试，以及「人话频率编辑器」（每 N 分钟小时、每周几、每月几号或第几个周几、每年 + 结束日期）。
- **表格与附件预览**：CSV / TSV 表头固定、按窗口渲染，列数不齐与截断都有提示；
  图片、PDF、DOCX、音视频、文本前若干行都能在输入区点开看。
- **词级行内 diff**：并排 diff 里标出改动行内具体改了哪些词，超长行退回整行着色。
- **侧栏分组与拖拽排序**：项目可拖拽排序、可归入自定义分组，重排带动画。
- **零会话三条起步路径**：选择文件夹 / 用最近的项目（能读 VS Code、Zed、Claude Code、Codex、
  OpenCode 的本机历史）/ 粘贴会话链接。

## 改动

- **折叠块不再瞬跳**：思考块、工具详情、过程步骤的展开收起改成行高动画，正文在收起动画结束后才卸载。
- **滚动更守规矩**：向上翻阅时流式追加不会再把你拉回底部，消息列两端加了渐隐遮罩。
- **等待首个 token 不再是一行裸文字**：改为准备 / 思考 / 调用工具的相位串行滚动。
- **标签栏与数字**：激活项改成滑动指示器，Token / 成本等数字变化时逐位滚动，行宽不抖。
- **入场动画**：新内容淡入并逐条错相，同一个块只播一次，切会话回来不整屏重播。

## 修复

- **工具结果定位指错块**：按块跳转时会落到无关的块上，表现为跳到工具输出类命中时没有高亮也不展开。
- **查找「计数在动、画面不动」**：命中落在渲染窗口之外时不会撑开窗口。
- **相位行留下看不见的空隙**：相位为空时仍然占位。
- **记忆读取报错不对**：文件不存在原本报成「在目录之外」，现在是「未找到」。
- **Windows 上的文件管理路径**：Git 路径的比较与转换此前在 Windows 上不可靠。

## 移除

- **设置里的搜索框**：与侧栏会话搜索、文件树搜索重复，删掉后设置仍按 11 个分区浏览。
