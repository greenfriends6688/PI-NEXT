# PI NEXT 0.1.9-beta.2（预发行）

> 0.1.9-beta.1 之后的 31 个提交：设置页重做、V5 画板族收尾、PWA 手机帧补齐，
> 以及一轮「用户逐条报、逐条量」的形态修正（时间轴、侧栏、浮窗、收藏星标）。
> 预发行通道：功能已可用，形态过渡期仍有少量缺口（见「已知」）。

范围：`v0.1.9-beta.1..HEAD` —— **500 个文件，+34,830 / −12,931 行**，31 个提交。

## 新增

- **设置：模型页重做**—— 列表页 + 一层钻入，砍掉三处重复入口；
  跨供应商模型选择器、默认模型落盘、目录刷新与逐模型测试。
- **设置壳与技能面板重做**：分节分层（hub → 二级页），长分节真的能滚（嵌入宿主那层
  不再裁高也不限高），技能面板接上加载 / 搜索 / 安装三条真实数据。
- **V5 画板族落地续**：转录族（D-03 / D-03d / D-03e）、子代理一列五节（D-12）、
  插件与 MCP（D-13 / D-15）、定时任务四帧（D-17）、用量帧 A→D（D-19）、
  归档与导入（D-21）—— 画板 DOM 逐节点抄进产品。
- **PWA 手机帧补齐**：M-05 设置分层、M-07 / M-08 / M-09 / M-10 / M-11 各帧、
  右栏六面板、窄屏手势原语与 i18n 文案。
- **即时提示（`InstantTooltip`）**：指针停到图标按钮上立刻出名称，不再等原生
  `title`（原生提示慢且样式不可控）。实现上进场那一刻把 `title` 挪到 `data-tip`、
  自己画一层 fixed 浮层，离开时原样还回去 —— 无障碍属性与可访问名称不受影响。
- **字阶补两档**：`--nx-f-2xs`=10（徽标 / 计数 / 极弱元信息）、`--nx-f-xl`=18
  （一级阅读标题）；阅读性正文的行高从 UI 的 1.60 分出来成 `--nx-lh-reading: 1.75`。
- **桌面壳接上局域网绑定监督器**：界面上的「启动 / 停止」在打包版里也真的生效。

## 修复

- **会话行重叠**（用户报「重影」）：根因是行距写死 48/54，而 v5 的行是 58.9。
  真值改成**量第一枚行的盒高**，窗口与偏移共用同一个数；行尾控件的高度在元信息格里
  预留，行高因此与状态无关（悬停一枚动作不再叠一次）。
- **时间轴「两种线」**：展开的工具卡自己画了一条 `left:9px` + v1 令牌的线，与
  `.d-step::before` 的 `left:10px` + `--nx-line` 差 1px；现在逐值对齐成一条线，
  卡片内缩也改回与步骤行文案同一条左缘（22 → 27px）。
- **竖线两端没接到图标**：首行漏算了图标的 `margin-top`，末行那条 `:last-child` 因
  兄弟是折叠壳从未生效（线尾多挂 6px）。两端都落到图标中心。
- **工具卡头首行对齐**：旧规则只给徽标 / 参数 / 图标下移 `--nx-sp-1`，漏了工具名，
  那 4px 又把 13px 图标盒顶到首行字面上方 —— 图标 / 工具名与命令第一行的差从
  3.2px 收到 1.1px（多行命令不再让整簇浮到两行正中）。
- **「PI NEXT 最后才出现」**：本轮还没有正文时（工具在跑的那几分钟）宿主只挂过程卡，
  身份行要等第一条正文。身份行抽成组件，无正文时先画一份；被中断那一支同样补上。
- **子代理会话默认收起**：此前默认全摊开，一屏被子会话吃掉；折叠箭头从元信息行
  挪到行右上角（它原来夹在「N 条消息」与四枚 hover 动作之间，且自己的 hover 底色
  在行里画出第二个盒子）。
- **顶栏浮窗点外面不关**：工具定义 / 系统提示此前只有触发钮的 toggle，点旁边任何
  地方都不消失 —— 接上共享的「点外面 + Esc」判据。
- **MCP 浮窗悬停就弹**：指针扫过顶栏弹出一整块服务器列表；改成只认点击（插件那枚
  保留悬停开）。
- **上下文浮窗中间空白过大**：两节从 `minmax(180px,1fr)` 封顶 260px，标签定宽、
  值紧跟其后 —— 值列仍对齐成一条竖线，空白回到一栏之内。
- **收藏星标两套读法**：原来是 `star` / `star-off`（一颗**划掉**的星），长列表里
  读成「坏掉」；现在空心 = 未收藏、实心 = 已收藏，三处入口统一。
- **服务端 worker 缓存不轮换**（真故障）：`public/sw.js` 的 `CACHE_VERSION` 取自
  `NEXT_PUBLIC_APP_VERSION`，而那是 package.json 的版本号 —— 开发期几十次构建都不变，
  static / shell 两个 cache 永不轮换，装到主屏的 PWA 继续吃旧 chunk（用户报
  「改的没效果」）。改成 **包版本 + 源码指纹**（git 短 sha + 脏标记），打包产物里
  没有 `.git` 就回落到包版本。
- **`.m-switch` 在手机上被顶成 48×36**：DSN-04 的 `min-height: 36px` 压过了库里
  写死的 `height: 29px`。撤销 min-height；并把它搬出 `app/design/v5-forms.css`
  —— 那个 `@import` 汇总层实测**会丢掉最后一段**，规则写在那里等于没写。
- **打开文件时右栏把同一棵树换槽**：树空掉 + 查看器变慢的根因。
- **共享右键 / 下拉菜单被设置弹窗盖成一块空白**：压层关系修正。
- **转录迷你地图**回到 0.1.8 的画板 53 形态（圆点导轨 + 贴左阴影 + 32px 紧凑头行）。
- 逐帧对齐 v5 板面：顶部对齐、间距、文件树默认态与转录区。

## 移除

- **「点头像翻版本号」彩蛋**：点一下字标会换成 `0.1.9-beta.1+…p1.0.0` 滚 3 秒，
  顶到行外、把搜索与折叠两枚钮挤没（用户原话「版本号炸了」）。版本号在侧栏底栏
  有一处，那才是它该在的地方；连带删掉 `useScramble`。
- **模型页的三处重复入口**（模型 / 供应商 / 目录）合并成一层钻入。
- 死资产与一次性调试脚本（含已零引用的 `.pw-*` 壳）。

## 已知

- **形态过渡期**：`npm run design:v5:land` 仍列出未进产品的画板类；`verify:boards`
  的几何对位覆盖率 19/30（改到哪张画板补哪张 spec）。真机 Safari / iOS 16.2 与
  Playwright WebKit 仍未验证。
- **样式字面量门禁是红的**：11 个键超出基线（`AgentSessionPanel` / `ChatInput` /
  `CodeFileEditor` / `app/error.tsx` / `app/pair` 等）。这轮没有跑 `--update`
  重新冻结基线 —— 那等于把新字面量洗成「存量」。要收口得逐条换成 token。
- **远程部署**：MCP 的 OAuth 回调只听 `127.0.0.1`；除 host-only 名单外的宿主环境
  变量仍会传给 stdio server 子进程。
- 源码包**不含** DMG / EXE（要安装包走 `mac-dmg-packaging-arm` /
  `windows-exe-packaging` 两个技能，产物用同一套 asset 接口补传到这个 release 上）。
