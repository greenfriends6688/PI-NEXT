## 1 · 最严重的 3 条

1. **助手身份行在 PWA 整体缺失** —— web 40+ 处 `.d-ava.brand`（品牌 logo 图 + 助手名 + 模型徽章，如 `D-03-transcript.html:88-90`），pwa 全库零处（唯一 `logo.png` 在 `M-10:407` 的信任横幅里）。这是转录区每回合都出现的品牌触点，也是用户点名的「头像要用品牌图」。
   · 附带：web 内部也不一致 —— `D-03:90` 写「pi」、`D-02:197` 写「PI NEXT」。**先定名，再两端共用**。
2. **会话动作菜单两端是两套** —— web `D-02:388-406` 12 项 / 3 段；pwa `M-04:344-355` 7 项、`M-11:238-246` 8 项。pwa 还保留了 web 明文禁止的「复制分享链接」，并把「删除会话」放在菜单最后一行且**没有确认对话框**（web 的确认模态 `D-26:58-72` 在 pwa 完全不存在）。
3. **右栏「调用轨迹 / Git / 审查」三块在 PWA 没有对应面** —— web `D-05:107-114` 六个页签；pwa 只有 `M-06`（文件/终端）与 `M-07`（浏览器）。这不是版式差异，而是「一端有另一端没有的分类」。

## 3 · 两端必须共用的文案 / 图标清单

- 侧栏分段：**项目 / 聊天**（唯二分段）
- 侧栏底栏：**手机与推送**（`smartphone`）· **设置**（`settings`）· 版本徽章；外观不上侧栏
- 新建任务：`square-pen` + **⌘N**
- 搜索：placeholder **「搜索所有对话…」**，且只在搜索态出现
- 会话行状态：未读 = 绿点（无数字）· 等你处理 = 文字徽章 · 运行中 = 行内转圈 + 扫掠线；行高 48 / 58
- 会话动作菜单（12 项 / 3 段）：置顶 · 重命名 · 归档 · 标记为未读 ｜ 在访达中打开 · 复制路径 · 复制会话文件路径 · 复制会话 ID ｜ 系统提示词 · 工具定义 ｜ 导出 HTML · 导出 Markdown；**不含「复制分享链接」**；删除不在菜单里且必须确认
- 顶栏：标题 + 副标题（项目 · 上下文 N%）· 运行中芯片 · 分支芯片（带分支名）· 右侧八枚动作
- 转录：助手身份行 = **品牌 logo 图 + 助手名 + 模型徽章**（名字两端同一个）· 回合结束行 = stopReason 人话 + 耗时 + token + 费用 · 失败态三动作
- 输入卡能力四项：**模型 / 思考强度 / 权限 / 工具与上下文**（web 文案同步改成这四个词）
- 权限档：每次问 / 本会话内允许读与查 / 全部自动允许 / 拒绝本会话内一切写操作
- 权限卡回法：允许一次 / 本会话允许 / 永远拒绝
- 输入卡其余：附件（`plus`）· 上下文环 · 完成提示音（`volume-2`）· 发送 / 停止（`arrow-up` / `square`）
- 设置 11 分节：通用 / 模型 / 技能 / 子代理 / 插件 / MCP / 定时任务 / 用量 / 归档 / 导入 / 手机与推送
- 右栏页签：轨迹 / 文件 / 终端 / 浏览器 / Git / 审查
- 查看器模式：源码 / 差异 / 预览（+ 不支持降级卡）
- 命令中心：分段 全部 / 命令 / 会话 / 文件；前缀 `>` 命令 · `#` 会话 · `@` 文件
- 系统态：Toast 只报已发生的事、无按钮；错误页两级；拖放三态（触屏可豁免但不得另造一套）
