# PI NEXT 0.1.10

231 个提交，2951 个文件改动。这一版集中补齐了「随手用」的部分：浏览器直接访问、
出门用流量连回来、任务定时跑、子代理成体系。

## 新增

**浏览器直接访问**

- 设置 → 远程访问 打开后，手机或任何设备用浏览器打开局域网地址，输入密码即可使用
  完整功能，**不需要安装应用**。
- **5G 控制**：不在同一网络时，一键生成公网地址，用流量也能连回这台电脑。地址在
  重启后保持不变，断线自动重连，不用重新配对。

**子代理**

- 内置 `general-purpose` / `explore` / `plan` 三种角色：查代码、做方案、干活的分工，
  只读角色的工具被实际限制为「改不了文件」。
- 角色可以自定义：写一个 Markdown 文件即可，指定它能用哪些工具、用哪个模型、
  推理强度多少。
- 可以让子代理**继承当前对话**作为背景，也可以完全从零开始。
- 支持后台运行（主对话继续干别的）、中途给运行中的子代理追加指令、完成后取回结果、
  在独立的工作区里干活不碰主工作区。

**定时任务**

- 按 cron 表达式 / 每天 / 每周定时运行一个任务，到点自动发起。
- 每个任务可以指定自己的工具、模型与推理强度。
- 连续失败自动停用；单次运行可设时长上限，超时收尾而不是永远挂着。

**MCP**

- 粘贴一条 `npx ...` 安装命令即可导入，不一定要手写 JSON。
- 内置市场：按下载量浏览、搜索、一键安装。
- 支持 OAuth 登录的远端服务器。
- 单个服务器可设只读策略。

**文件与预览**

- Markdown、HTML、图片、视频、PDF 打开默认就是**预览态**，源码一键切换。
- 右栏文件树支持显示/隐藏被 Git 忽略的文件，改动带行数统计。
- **Mermaid 图表**直接渲染成图；```html / ```svg 围栏一键预览；音频文件可直接播放。
- **Artifacts**：回复里点名一个块，应用把它画出来，改动即时可见。

**对话与日常**

- **定时提醒之外，任务完成有提示音**；流式输出时实时显示 token 速度。
- **`!命令`** 在输入框就地执行 bash，输出直接进上下文。
- 顶栏 Git 状态一目了然：当前分支、改动数、worktree 一键切换。
- 设置里的每模型开关：不常用的模型可以隐藏，不删配置。

## 修复

- 打开文件树不再整窗崩溃。
- 顶栏 Git 状态不再导致整窗白屏。
- 浏览器端可以正常加载图片与文件预览。
- 超长会话导出调用轨迹不再白屏。
- 会话在仓库里时，顶栏状态、diff 与文件树的若干显示错误。

## 移除

- **电脑操控**：其驱动要求 macOS 13+，与支持的系统不符，整体下线。
- 每轮改动卡片上的「文件」按钮：路径列表本身就在卡片里，点任意一条直接打开那个文件。

## 已知

- Windows 安装包与 DMG **未做代码签名**，首次打开系统会提示；选择「仍要打开」即可。
- 使用 5G 控制时，若两端都在严格限制 UDP 的网络里（手机流量常见），可能连不上——
  这种情况需要自建中继服务器，同网络与大部分家庭宽带不受影响。
- `.pptx` / `.pdf` 为只读预览。
