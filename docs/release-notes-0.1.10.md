# PI NEXT 0.1.10

> `0.1.9` 之后的 231 个提交。这一版换了宿主：壳子来自 FastVibe 0.19.5，核心是 PI NEXT 的
> 引擎与渲染层 —— 所以这一版里「换壳」和「三个批次的功能」一起进来。

范围：`v0.1.9..HEAD` —— 2951 个文件，+234559 / −368727 行。

## 新增

**宿主与形态**

- **独立 Web 端**：`pnpm web` 起一个无 Electron 的浏览器客户端，远程访问监听本身也提供
  同一个客户端 —— 手机浏览器直接打开局域网地址就是完整的 Pinext。
- **5G 控制（Cloudflare 隧道）**：设置 → 远程访问 → 开启，拿到一个 `https://*.trycloudflare.com`
  地址，手机用流量也能控制电脑。隧道独立成进程、地址跨服务重启存活、断了无限重连、
  60 秒没注册到边缘就杀掉重来。
- **调用轨迹**：右栏新标签，pi 导出的完整历史（侧栏树、搜索、过滤），长会话的递归树遍历
  改成了迭代 —— 5000 条以上的单链会话不再把页面打崩。

**三方对比落地（Batch 0–2）**

- **Mermaid 图、` ```html ` / ` ```svg ` 围栏内联预览、音频预览**（`components/chat/mermaid-block.tsx`）。
- **Artifacts**：回复可以点名一个块，应用把它画出来。
- **定时任务**：cron 规则、机器级租约、失败自动停用、每任务时长上限；**每任务工具预设 /
  模型 / 推理强度**。
- **worktree 切换器**：一个会话可以挂到隔离的工作区里干活，侧栏切换。
- **MCP**：粘贴 `npx ...` 这类安装命令直接导入（不只是 JSON）；**市场**（官方目录 +
  自定义目录）；**OAuth 登录**（远端服务器要求 OAuth 时）。
- **模型与技能**：模型可以隐藏而不删除；技能可以逐个关掉（保留文件但不再放进提示词）。
- **完成提示音**、**`!command` 就地执行 bash**、**流式实时 t/s**、**i18n key 对齐门禁**。

**子代理（照 pi-web 移植）**

- 三个内置角色 `general-purpose` / `explore` / `plan`，提示词与工具集逐字来自 pi-web ——
  两个只读角色只给 `read/grep/find/ls`，「不要改文件」是能力限制而不是一句请求。
- **`inherit_context`**：角色可以要求把父会话的消息作为背景带进自己的系统提示
  （上限 50,000 字符），pi-web 同一句话、同一个上限。

**云服务（`services/cloud/`）**

- 账号 / 设备 / ICE / 信令四合一的 Node 服务，外加 **Cloudflare Workers 宿主**（两个
  Durable Object），同一份核心跑两个宿主。
- 仓库内测试：Node 宿主 14 项，Workers 宿主 3 项（假 Durable Object，真实路由）；
  真实客户端连真实服务的登录链路 2 项。

## 修复

- **图标表崩溃**：浏览器宿主把 `workspace:file-icons` 答成了一个不是那个形状的桩
  （`{ files: {}, folders: {} }`），每次渲染 `FileIcon` 都读 `undefined.fileNames["auth.ts"]`
  —— 打开任何文件树就把整个窗口打掉。现在两端共用真实表（2135 个文件名 / 1377 个扩展名），
  且表不完整时退化为通用图标。
- **顶栏 hook 顺序崩溃**：`git-status-popover` 把 `useEffect` 放在了提前 `return null` 的
  下面，第二次渲染多出一个 hook，React #310 直接接管窗口。
- **web 客户端加载不了任何文件**：`pathForFile` 永远存在导致 `isWebClient()` 恒为假，
  浏览器里去请求一个只有 Electron 才有的私有协议；`/api/media` 又要求同源 GET 不会发送的
  `Origin` 头。两处都修了，顺带把一次性 web 令牌从 localStorage 里拿出来（它每次启动都换）。
- **文件预览默认打开成源码**：会渲染的类型（Markdown / HTML / 图片 / 视频 / PDF）现在
  以预览态打开；按钮顺序不变。
- **调用轨迹导出**：从「字符串塞进 `srcDoc`」（被应用 CSP 拦掉内联脚本）改为独立文档，
  `pinext-media://` 与 HTTP 两条路都带同样的页面 CSP。
- **电脑操控整体下线**：驱动按 macOS 13 编译，这台机器用不了；相关依赖与设置一并移除。

## 已知

- **Windows 安装包未做代码签名**（这台机器的钥匙串里没有有效身份），SmartScreen 会提示；
  右键 → 属性 → 解除锁定，或继续安装。
- **DMG 同样未签名**，本机构建没有 quarantine 属性，直接打开即可；发给别人会被 Gatekeeper 拦。
- Cloudflare Workers 宿主装不下 TURN：两端都是对称 NAT（手机流量很常见）时，跨网络直连
  需要另外部署 coturn。同网络与大部分家庭宽带不受影响。
- `.pptx` / `.pdf` 仍不可编辑；可编辑的只有 `.docx`。
