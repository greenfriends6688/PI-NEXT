# PI NEXT v0.1.8

这一版把三件积压的事一起收了：**手机端从「同构」改成「按得准」**（窄屏顶栏 7 枚减到 3 枚、
次级动作搬进带文字的宫格、两条盖住内容的覆盖式工具条拆掉）、**四条大功能接进来**
（定时任务、三条入站渠道、LAN 扫码、MCP 1.0 原语）、**字号与布局的若干真缺陷**。
改动面：312 个文件、+48.4k/−4.4k 行，测试 3512 项全绿。

## 新增

- **手机「更多动作」宫格**（窄屏）：调用轨迹 / 生成标题 / 子代理 / 分支 / 导出 HTML /
  导出 MD / 发送图片，七格**带文字**（图标在上、标签在下），锚在输入卡上方。
  窄屏顶栏放不下的动作终于不用「猜图标」了。桌面形态一字未动。
- **顶栏会话身份副行**：`cwd 目录名 · 上下文 N%`。窄屏看不到会话在哪个目录，
  上下文环也只在浮窗里报数 —— 这两项是那块屏上**唯一**说清「我在哪、还剩多少」的地方。
- **定时任务**：无人值守运行，每一轮开一个子会话，工具调用自动放行，agent 知道这是定时触发。
  设置里新增「定时任务」分节；调度器挂在 `globalThis` 上（路由与 instrumentation 是两份模块实例）。
- **三条入站渠道真跑通**：Telegram（长轮询，零依赖）、微信（挂自家 iLink bot 平台，
  扫码换 token）、飞书 / Lark（device-flow 三步一键建应用，不用预建）。
  出站 `im_send` 覆盖飞书 / 企业微信 / 钉钉 / Slack / Telegram + 自建 webhook 五家。
- **LAN 扫码连接**：令牌由应用自己生成（`~/.pi/agent/lan-access.json`，0600），
  第一次打开「手机与推送」即视为同意。启动器盯着那份配置，开关一变自动重启子进程 ——
  「启动 / 停止」从此是真开关，不用敲命令行。6 位配对码 + 二维码扫码直连。
- **agent ↔ agent 信箱**：`agent_mail` 一个工具补齐子→父 / 兄弟 / 父→全体三个方向
  （原来只有父→子）。信先落盘再投递，会话当下不可用也不丢。
- **MCP 换成 pi 1.0 官方原语**：配置的读/写/删/改、校验、OAuth 全部转发官方实现
  （跨 agent 的配置发现保留，pi 没这能力）；补 codemode / tool-search 曝光、
  密钥掩码、导入（json / 链接 / CLI 三种来源）、撤销、真连日志。
- **「使用默认目录」**：按天开一个新文件夹 `~/pi-cwd/<YYYYMMDD>`，
  第一次用的人不会落进一个已经堆着他数据的目录。
- **Mac拟物材质皮肤**：实板而不是玻璃（三个不透明度拉到接近不透明，否则浮凸投影会断）；
  夜间端强调色抬到 `#4a8fe0`（`#2f7de0` 在深底上只有 4.0:1，过不了 AA）。

## 修复

- **手机上那排控件「点不准」**：tab 关闭钮 11px → 命中 21、概览钮 28 → 35、
  右栏页头两枚裸钮 24 → **36×36**、抽屉底栏手机钮 22 → 33。
  手段是盒子一个像素不动、`::after` 外扩命中区（画板规格不动）。
- **两条覆盖式工具条拆掉**：窄屏顶栏那条**盖住会话标题**（五枚动作放不下只能铺浮层），
  输入区行二那条把上下文环与声音藏起来。拆掉后窄屏顶栏是
  菜单 / 会话身份 / ⋯ / 面板开关，四枚一行放得下，**标题再也不会被盖**；
  行二常驻思考 / 权限 / 工具预设 / 速度 / 上下文环 / 发送。
- **横屏矮屏（≤1024 且 ≤500）**：卡片实测宽度 < 700 时会把工具条退回两行，
  而横屏档存在的全部理由就是「高度是稀缺资源」（两行在 390 高里占掉约 150px）。现在单行。
- **聊天正文那条「平行字号梯度」并回设计五档**：界面侧本来就齐（实测无一处离档），
  不齐的是正文另有一条以 **14px** 为基准的梯度 —— CSS 默认写 14、JS 默认值 13、
  offset 基准 13，三处三个数，于是「设置里显示 13、正文渲染 14」。改完正文只剩
  12 / 12.5(等宽) / 13 / 15。
- **定时任务面板「太局促」**：根因是组件注释承诺过的那段 `.fork-automation-*` CSS
  **从来没写**。于是提示词 textarea 被 `.pw-input` 的固定高压成 28px 单行（现在 112px 四行）、
  四个数字/时间输入被拉满整列（现在用画板已有的 `.pw-numin` 90px）、
  星期芯片没有间隙与换行、运行历史是带圆点的裸 `<ul>`。
  顺带修了四处重复文案：「提示词」与「子会话复用」各既是分节标题又是字段标签、
  模型的空选项把整句 hint 当标签、固定间隔下的星期芯片字段与外层选择器都叫「重复」。
- **侧栏列表下拉刷新**：手机上原来只有一条 2.5s 的运行态轮询，PC 上新开的会话没有刷新口。
- **9 个复制点接上失败反馈**（承上一版）、**九个指针会「点了没反应」的地方**逐个定位到根因
  （MCP / 插件两枚图标、⋯ 菜单里的系统提示词与工具定义等）。
- **`lan-supervisor` 测试在全量套件里随机红**：根因是 `fs.watch` 在负载下**丢事件**而不是迟到
  （实测固定 sleep 加到 8s 仍不等），改成「等条件 + 重发」，重发间隔 700ms
  （必须大于 500ms 去抖窗口，否则每 200ms 一次会把那个 timer 反复 clearTimeout 掉）。
- **CSS 合并丢注释**（`try-merge` 合并时）、**新增 `.fork-changes-*` 死样式**清理。

## 移除

- **「任务与日程」工作区**：功能回到输入框左上角的待办，中间那个吸底浮层撤掉。
- **「项目知识」与「思考档 token 预算」**两个分节。
- **ChangesPanel**（变更来源面板）：它依赖的库一直只是把 git 输出再包装一层，
  而右栏已有 git 图谱页在渲染同一批数据。
- **⋯ 菜单里的「前往配置」与「调用轨迹」**两个重复入口（分别已在设置与宫格里）。
- **tab 的重复渲染**（调用轨迹与 git 图谱各渲两份），并加了计数断言防再犯。
