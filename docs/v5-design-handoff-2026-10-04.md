## 2 · 对比结论（ZCode × Aether × 本仓）

完整证据见 `docs/feature-matrix-zcode-aether-2026-10-04.md`（380 行，逐条源码路径）与
`docs/ref-feature-matrix-2026-10-04.md`。本轮已复核 7 条关键结论（全部成立）：

| 结论 | 证据 |
|---|---|
| 本仓**没有**命令面板 | 全仓只有 `lib/shortcuts.ts` 注释提到 ⌘K，实现里没有这一项 |
| 本仓**没有**插件商店 | `PluginStore` / `plugin-store` 零命中（技能市场与 MCP catalog 有） |
| 本仓**没有** onboarding / 保存的工作流 / 消息重做 / 高对比开关 | 四个关键词全仓零命中 |
| 本仓硬能力比两个参考项目都厚 | 转录、查看器、终端/浏览器、Git 面板、定时任务、用量、LAN/IM/机器人、皮肤工作室 |
| ZCode 的 iOS/Android 模拟器**搬不了** | 插件本体不在那个仓库（`packages/` 里没有 `ios-simulator-plugin`），走 `simctl`/`adb`，依赖本机 SDK |
| BoardUI **不能整体照搬** | Tailwind v4 + React Aria + 自带 400 令牌 = 第二套样式来源（本仓 2026-09-30 删过一次） |
| BoardUI 的**动效手艺值得抄** | 已抄 11 组关键帧 + 环绕光带 + 四态思考指示器，见 `DIVERGENCE.md §A2` |

**本轮新增能力（V5 已画板、未落地）**：命令中心 `D-16`、插件商店 `D-10`、设备预览 `D-17`、
首启引导 + 保存的工作流 `D-19`、扩展插槽声明表 `D-20`、输入框环绕光带与四态思考 `D-21`。

## 3 · 两个「口」在哪，怎么用

**口一：落地清单（不靠人记）**

```bash
npm run design:v5:land      # 每张画板哪些类还没进产品 + 触达哪些产品文件
npm run design:v5:batch     # 按批次给执行顺序
```

**口二：触发口令**

用户说「**按 v5 设计落地**」/「启动改版 v5」→ 执行者按 `LANDING.md §3` 的五步硬性顺序走，
不许跳步、不许凭记忆。落地完每项重跑清单，看队列是否真的少了一项。

**四个仲裁者（都可复算）**

```bash
npm run design:v5            # 静态：令牌/类/图标/接线/比例带单位/内联设计值
npm run design:v5:shots      # 运行时：真浏览器逐张出图 + 每个交互件真点一遍
npm run design:v5:land       # 清单：未落地队列 + 死类 + 漂移类
node scripts/board-diff.mjs scripts/board-specs/<x>.mjs   # 几何：画板 vs 产品逐选择器对数
```

## 4 · 这一版专门修掉的「假绿灯」

历史三次落地失败，编译器 / 单测 / 人眼评审**全都绿**。V5 的门禁现在能抓住这四类：

| 静默失效 | 谁抓住 | 怎么抓 |
|---|---|---|
| `--nx-r-*` 同时是字阶比例与圆角 → 六档字阶全死 | `check-v5` | 「`*` 右侧的比例必须无单位」+ 每个字阶的 calc 逐个验算 |
| 类名对上了、DOM 结构没对上 | `LANDING.md §4` + `board-diff` | 只抄 DOM 原文 + structdiff + 几何对数 |
| 写了 `data-demo-tab` 但漏了 `data-demo-tabs` → 点了没反应 | `check-v5` + `shoot` | 页签必须挂在容器里 + 真点一遍断言状态迁移 |
| `restartMotion` 用 `offsetWidth` 强制回流 → SVG 动画永远重播不了 | `shoot` | 动画 currentTime 回零才算「重播成功」；已改用 `getBoundingClientRect()` |
