// initialize { "protocolVersion": "2025-06-18", "serverInfo": { "name": "filesystem", "version": "0.6.2" } } // tools/list → 11 个工具 // resources/list → 0 个资源 ✓ 1.4s · 11 tools

这一张在定什么

  • 插件与 MCP 共用「列表 + 详情」骨架，但列表行的副标题给的是不同信息：插件给「版本 · 资源数」，MCP 给「传输方式 · 作用域」。
  • 连接状态用徽章三色：已连接（success）/ 未连接（warning）/ 需要授权（error）/ 已禁用（中性 + 整行弱化）。
  • MCP 的 Basic 与 JSON 是同一份配置的两种写法，用芯片单选组切换；JSON 模式只读展示当前配置，避免两处都能改导致的漂移。
  • 环境变量的值默认打码，右侧一个眼睛图标切换显示。凭据本身不落配置文件。
  • 导入时同名冲突给 warning 徽章而不是阻止，让用户自己决定覆盖还是跳过。
  • OAuth 走「复制本地地址 → 浏览器授权 → 回来测试」三步，凭据存系统钥匙串，并给「清除凭据」出口。
