这一张在定什么

  • 全应用只有一套菜单原子：行（6px/8px 内边距、圆角 4、悬浮 6% 深色容器）+ 分组标题（11px 弱化色）+ 发丝分隔线 + 搜索头（钉顶不滚）。
  • 八种行类型：普通 / 选中 / 勾选 / 带快捷键 / 带子菜单 / 带反馈标签 / 禁用 / 危险。禁用用透明度不用灰色文字，危险用 error 色文字不用红底。
  • 子菜单只做一级，右侧一个 chevron，不做嵌套第二级。
  • 长菜单必须带搜索头（新建任务、工作区切换、标签概览、模型选择），内容区封顶 320 高后内部滚动，搜索框不随滚动。
  • 工作区切换器的两枚徽章并排：在跑数（accent）+ 等你数（warning），当前工作区也挂；对勾在最右，徽章排它左边。
  • 菜单宽度按内容收：行内菜单 230、带副标题的 300–320，不强行统一——统一的是行的密度与配色。
