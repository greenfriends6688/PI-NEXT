这一张在定什么

  • 壳的比例：侧栏 280 / 右栏 420 / 顶栏 36；转录居中宽度上限 800，输入框同宽。右栏展开时主区让位，聊天仍居中于剩余宽度。
  • 侧栏一行 = 两种高度：项目与导航行 30px，会话行 48px（两行文字 + 状态点）。会话行用 7px 状态点表达状态，不写状态文字。
  • 过程时间轴是唯一的过程形态：一轮内的工具调用收成一条带竖线的步骤流，汇总行给出计数；失败行在竖线上就地转 error 色，不另开一张卡。
  • 权限卡是唯一用强调色边框的卡：它要抢注意力；与侧栏的 warning「等你处理」在语义上分工（决策 vs 提醒）。
  • 回合结束行：stopReason 徽章 · 耗时 · ↑in ↓out · 成本，右端一条发丝线收尾，再给一个复制。
  • 输入框在三种状态下的差异：空态发送键是灰的、进行中是红色方块、空闲是强调色箭头；运行中多一个「N 条排队」徽章。
  • 文件树里改动的文件只用右端一个 warning 小点标记，不写「M」字母、不用颜色铺底。
  • 用量不进长条，收进输入框左下的那个圆环：圆环本身只给一个百分比；悬浮（或键盘聚焦）才展开一张浮窗，把 Context / Rules / 本轮 ↑↓ / 花费 / 结束原因 与「压缩上下文」一起给出。输入框下面**不再有第二条横条**。
  • 图标与文字一律垂直居中：icon + 文字 / 文字 + icon 的组合不许出现「文字比图标低」。实现靠清掉 <i data-ico> 与内层 svg 的行高 strut，见 assets/board.css 的「图标与文字的垂直对齐」一节；改动后 scripts/check-align.mjs 应报 0 处偏差。
