这一张在定什么

  • 编辑态与只读态只差头部三个东西：一枚「未保存」徽章、一个撤销、一个主按钮的保存（带 ⌘S kbd）。正文区完全一样。
  • 编辑区页脚给三样定位信息：行 · 列、语言 · 行尾 · 编码。不用状态栏占布局。
  • 保存冲突给三个明确动作（用磁盘 / 覆盖磁盘 / 先看差异），不做自动合并——合并结果无法预期。
  • CSV 用真表格不用等宽文本：表头吸顶、首列行号、数字列右对齐 + 等宽数字、宽表横向滚动。
  • frontmatter 单独成卡：YAML 头解析成 键 / 值 两列，布尔值给徽章；正文照常 Markdown 渲染。不改写文件，只换呈现。
  • 图片预览的工具栏只有四样：缩放百分比（可点开）、放大、缩小、适应窗口 / 1:1。拖拽平移不给按钮。
  • 滚动淡出用上下两条渐变遮罩（pointer-events: none），只在真能滚的时候出现；它是提示不是装饰。
  • 「与 HEAD 对比」是一个覆盖层，不是一个视图模式：整个内容区换成只读 diff，顶部一条横幅写明在看什么 + 「返回源码」；关掉回到原视图，不丢滚动位置、不重开标签。
  • 文件已从磁盘删除时不能给空白面板：对比开着就给删除说明 + 与 HEAD 的差异；对比关掉就一条 role="status" 说明「已不在磁盘上」。
