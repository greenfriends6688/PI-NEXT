这一张在定什么

  • 自定义命令的三段式编辑：命令名（前缀 / 单独一格）+ 描述 + 参数提示，下面是正文长文本区；占位符用 {{范围}}，并在下方给一条提示。
  • 归档分两块：项目归档在上（可展开看会话、可整项目恢复），归档会话在下（按项目分组、逐条恢复或彻底删除）。
  • 「文件已消失」的归档会话默认隐藏，用一个开关显式打开，并用 warning 图标标出——避免用户以为数据丢了。
  • 彻底删除是危险动作，收在底部一条 error 提示里（含「清理 30 天前的归档」），行内只给一个垃圾桶图标。
  • 导入按四类资产分页签（会话 / 模型 / 技能 / MCP），每类里按来源分组、可全选；右侧常驻「本次选择」与「上次结果」两栏。
  • 导入结果三色：成功（success）/ 跳过（warning，附原因）/ 失败（error，附失败位置），并给「看详细日志」。
  • 扫描是只读的：这一句写在副标题里，减少「点了会不会改我东西」的顾虑。
