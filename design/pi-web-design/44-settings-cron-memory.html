这一张在定什么

  • 定时任务的「频率」是八选一的芯片组，选中后再按类型显示对应的补充字段（时间 / 星期 / 日期 / Cron 表达式），不是一上来就摆一堆输入框。
  • 任务行的开关在最左（对齐、可扫视），中间是名称 + 下次运行时间，右侧是上次结果徽章。
  • 运行历史是列表不是表格：每行给「时间 · 触发来源 / 耗时 · 成本 · 消息数」两行，右侧一个「打开会话」。触发来源（定时 / 手动 / 重试）写在时间后面。
  • 「错过一次」是独立状态（warning 徽章），与「失败」区分——错过是因为机器没开或不在空闲窗口，不是任务本身出错。
  • 记忆分节顶部先给状态（已装启用 / 已装停用 / 未安装），未安装时整块换成安装引导。
  • 记忆工具逐条列出并标注是否允许自动调用，让用户知道 agent 能拿记忆做什么。
  • 只读的记忆文件用弱化行 + 「只读」徽章，仍可点开查看但不可编辑。
