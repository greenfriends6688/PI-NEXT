这一张在定什么

  • 两个分节共用一套骨架：顶部一行开关组（内置 / 并发）→ 左列表 + 右详情 → 详情底部一组开关。
  • 作用域用分组标题表达，不用彩色标签：项目 / 全局 / 工作区 / 内置 / 路径。被覆盖的项给一枚中性「被覆盖」徽章，不标红。
  • 子代理编辑器是两栏字段网格（作用域 / ID / 显示名 / 模型覆盖），下面是长文本区（描述 / 系统指令），再下面是工具与资源芯片。
  • 工具与资源用芯片表达：已选工具用强调淡底芯片，未选的用「+ 加载技能 / + 加载扩展」入口芯片。
  • 技能详情里的 SKILL.md 可编辑，磁盘冲突时给「放弃我的修改 / 覆盖磁盘」两个明确动作，不用自动合并。
  • 市场切换是两个芯片组成的单选组，与「安装到哪」的下拉分列两端。
