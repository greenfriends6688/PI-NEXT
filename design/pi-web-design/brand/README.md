# 品牌标记

> 应用图标与壳内标记的来源。**不是画板**：不进 `README.md` 的画板索引，也不参与画板渲染。
> 画板里侧栏顶部那个 20×20 的方框标记就是按本目录的几何画的。

## 几何

字母 **π** 的极简写法：一条横杠 + 两条竖腿，24 视口内，描边 2，圆头圆角。
右下角一个强调色圆点，作为「正在跑」的视觉锚点（对应侧栏品牌行）。

```
横杠  M4 7  →  M20 7
左腿  M8 7  →  M8 18
右腿  M16 7 →  M16 18
锚点  circle(20, 7, r=1.6)
```

## 取色

只用 `assets/tokens.css` 的值，不写字面量之外的色：

| 部位 | token | 浅色值 |
|---|---|---|
| 底板 | `--n-canvas` | `#fbfbfc` |
| 描边 | `--n-border-subtle` | `#e2e2e7` |
| 笔画 | `--n-strong` | `#1e1e26` |
| 锚点 | `--accent` | `#5566d8` |

## 两份产物，一份几何

| 用处 | 文件 | 说明 |
|---|---|---|
| 设计稿 / 品牌留档 | `app-icon.svg` | 带底板，128 视口 |
| 壳内标记（侧栏 / 空态 / 登录页） | 画板内联 SVG | 无底板，viewBox 收到标记外框，笔画取 `--n-strong` |

**产品侧不动**：现有实现用的是 `public/pi-agent-logo.svg`（蓝紫渐变的多色位图矢量）。
本设计系统只保留单一强调色，所以设计稿里的标记改成单色；这是一处**有意的偏离**，
记在 `DIVERGENCE.md`。真要落地，需要先裁定是否放弃现有渐变标识。
