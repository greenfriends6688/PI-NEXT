## 尺寸与取色纪律

- **标记**：`public/pi-next-logo.png` 原图直出，按宽度等比缩放。侧栏 `.pw-logo` 胶囊内 14px
  （折叠导轨 24px 胶囊内 17px）。不裁切、不重绘、不加底色。
- **字标**：`public/pi-next-wordmark.png` 按高度等比缩放，高度 10px ≈ `.pw-brand` 的 13px 字号。
  **只在浅色主题用图**：字标里「PI」是深藏青（实测最暗 `#010129`），压在深色侧栏底上等于看不见，
  深色主题回落实色文字「PI NEXT」（见 `DIVERGENCE.md` A-2）。
- **图标**：`scripts/gen-icons.mjs` 从标记生成，不引入第二份母版。
