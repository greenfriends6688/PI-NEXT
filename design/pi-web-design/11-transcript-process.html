这一张在定什么

  • 过程时间轴替代逐条工具卡：一轮内的工具调用收成一条带竖线的步骤流。汇总行给 N 个文件 · M 条命令 · K 次工具调用 · J 次失败 · L 段思考，右侧一个状态徽章。
  • 失败就地标红，不另开卡：失败步骤的图标与动词转 error 色，右侧挂一枚 失败 徽章；要看详情才展开成工具卡。
  • 竖线的起止被裁掉：第一行的竖线从图标中心开始、最后一行到图标中心结束（::before 的 top/bottom 偏移），视觉上是一条线串起所有步骤。
  • 折叠规则：一步不折（直接显示）；多步完成后折成一行；进行中默认展开；思考块单独可折。
  • 工具卡只在需要看输出时出现：等宽输出区 + 页脚「原始入参 / 复制」，展开态在底部另有一条收起条（整条可点，不只是标题行）。
  • 失败不靠整卡着色：只换两处——状态图标转 error、输出区底色转 error.soft。边框仍是发丝线，不加左侧彩条、不给整卡描红。
  • diff 只读：没有 Keep All / Reject All。头部给 +n −m、视图切换；行悬浮才出「在文件面板中定位」，不占常驻空间。页脚写一句「改动由 agent 自己落盘」。
  • 子代理卡是唯一有左侧强调线的卡（2px），表示父子层级；运行中用 accent 线，完成换 success 线。展开后：嵌套工具行（与主转录同一套步骤语法，缩进一级）→ ↳ Subagent Output 一行 → 复制结论与一对反馈图标。
