这一张在定什么

  • 弹层只有一个尺寸族：宽 320，圆角 6，边框 1px 发丝线，唯一一种阴影（--shadow-popover）。没有二级边框、没有箭头。
  • 行高与悬浮：行内边距 6/8，悬浮出现 6% 深色容器（--overlay-hover），当前项用强调淡底 + 强调色文字 + 右端对勾。
  • 搜索框钉在顶部，不随内容滚动；内容区封顶 320 高后内部滚动，键盘上下键把高亮移出视口时自动露出。
  • 分组用小标题（11px、弱化色、全大写或来源名），分组之间用一条发丝分隔线。
  • 「不可用」用透明度 + 弱化图标，不划删除线、不用红色；右侧给一句原因（未启用 / 未连接 / 已禁用自动调用）。
  • @ 与 / 是同一个弹层的两种入口，都带搜索框；@ 分四组（文件 / 会话 / MCP / 待办），/ 分四组（内置 / 自定义 / 技能 / 扩展）。
