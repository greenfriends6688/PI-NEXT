注：命令名是 .pw-mono（等宽、不省略、可折行），描述才是单行省略——名字要能被扫，描述看不清可以悬停。没有搜索框：筛选就是你在输入框里已经打出的那几个字。

这一张在定什么

  • 窄弹层只有一个尺寸族：宽 320，圆角 6，边框 1px 发丝线，唯一一种阴影（--shadow-popover）。没有二级边框、没有箭头。模型 / 思考 / 工具 / 权限 / @ 五件都归这一族。
  • 行高与悬浮：行内边距 6/8，悬浮出现 6% 深色容器（--overlay-hover），当前项用强调淡底 + 强调色文字 + 右端对勾。
  • 搜索框钉在顶部，不随内容滚动；内容区封顶 320 高后内部滚动，键盘上下键把高亮移出视口时自动露出。
  • 分组用小标题（11px、弱化色、全大写或来源名），分组之间用一条发丝分隔线。
  • 「不可用」用透明度 + 弱化图标，不划删除线、不用红色；右侧给一句原因（未启用 / 未连接 / 已禁用自动调用）。
  • / 命令菜单不归 320 那一族：它与输入框同宽（left:0; right:0 贴在输入框上，上限 --composer-max 800）。命令多的那一族要的是「一次看见有多少」，320 宽会逼用户滚动找命令。
  • / 菜单里没有搜索框（实现如此）：筛选就是你在输入框里已经打出的那几个字，菜单只是把它列出来。再加一个框等于让用户输两遍。
  • 命令菜单是分组 + 组内自适应列：分组标题是 .pw-pop-title 且sticky 钉顶（滚到下一组时上一组的标题不跟着走会迷路），右端给该组条数；组内用 repeat(auto-fit, minmax(220px, 1fr))，800 宽下自然排三列。
  • 命令名与描述的省略规则相反：命令名等宽、不省略（长名字宁可折行，它是可执行的标识符）；描述单行 + 省略号（看不清可以悬停拿 title）。
  • 输入历史是一枚贴在输入框上方的弹层：30px 头（只有 history 图标，没有文字）+ 序号加两行截断的正文，↑ 唤出且只在输入框全空时唤出。选中只填入，不发送。
