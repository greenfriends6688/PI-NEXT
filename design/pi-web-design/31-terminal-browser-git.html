这一张在定什么

  • 终端与浏览器都住在标签里，与文件标签同一套标签条；终端标签给 terminal 图标、浏览器给 globe、Git 图给 git-branch（单例，不可关）。
  • cwd 与连接状态常驻在标签条下方一条，不塞进标签文字里；退出后用「退出码 N」徽章 + 重启按钮。
  • 终端输出保留在卡里：进程退出后输出不消失，只加一行「进程已退出 · 输出仍保留」。
  • 浏览器视口预设五项：填满 / 390 / 768 / 1024 / 1280，选中项用强调淡底。空态给一句「输入一个地址，预览本地服务」。
  • Git 图谱的泳道只有 44px 宽，节点 8px；普通提交用 accent 点，merge 提交用 warning 点。提交下方列出该提交的变更文件，按新增 / 修改 / 删除分色。
  • 标签溢出折叠成 +N 标签，点开是标签概览弹层：过滤、全部标签、最近关闭（可恢复）、关闭其他 / 全部 / 清空。
