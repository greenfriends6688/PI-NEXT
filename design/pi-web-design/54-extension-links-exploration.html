这一张在定什么

  • 扩展 widget 挂在输入框上方，是一个带来源标签（@pi/plugin-git）的可折叠块；折叠后只留一行摘要。它不抢输入框的焦点。
  • 扩展状态条钉在应用底部、高 22，等宽小字；左侧是仓库状态、中间是 agent 运行态（accent 色）、右侧是模型与上下文。窄屏换行不横向滚动。
  • 链接给三选一：应用内浏览器 / 系统浏览器 / 复制链接。默认记住上次选择，⌘ 点击强制系统浏览器。这是为了解决「应用里有浏览器面板但没有任何链接调它」。
  • 附件预览按类型分六条渲染分支：图片 / PDF / DOCX / 音频 / 视频 / 文本，其余给「只能下载」。分支选择交给一个纯函数，组件只负责画。
  • 探索分支的抬头条在转录顶部（不是浮层）：写明「从主线的第几轮分出来」、给「看来源那条」与「把结论带回主线」。
  • 右栏探索面板是只读并排视图，顶部一条说明「这里不能发消息」；底部三个动作：带回主线 / 打开为独立会话 / 切过去继续聊。
  • 右栏刻意不做第二个可交互聊天面板——那要把 SSE、composer、模型选择整套在右栏再搭一遍，容易和主线状态打架。这一条写在面板页脚，防止后来者「顺手补上」。
