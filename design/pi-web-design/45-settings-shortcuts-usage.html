这一张在定什么

  • 快捷键表分两列铺（基础 / 布局 + 外观 + 保留键位），每组一个小标题。行是「命令名 + 键位芯片 + 清除按钮」，键位芯片用等宽字 + 发丝边框 + 圆角 3。
  • 录制态与冲突态都用颜色表达：录制中键位芯片转强调色、右侧多一个「保存」；冲突键位芯片转 error 色，并在底部汇总一条冲突提示 + 一个「自动分配」。
  • 保留键位不可改：右侧是「保留」/「系统占用」徽章而不是清除按钮。
  • 用量顶部先给范围切换（7 天 / 30 天 / 1 年 / 全部）与「重新扫描」，再给一行缓存说明——避免用户以为「没算」。
  • 九张统计卡是 4 列网格：每张卡是「标签 / 等宽大数 / 一行补充」。全应用唯一用大号等宽数字的地方。
  • 图表只用三种色：accent（主）、n-border（次要）、n-hover（其它）。热力图四档用中性阶 + 强调色的透明度阶梯，不引入新色相。
  • 「按项目」用行内进度条（5px 高、accent 填充）而不是饼图，因为项目数少、需要精确比较。
