这一张在定什么

  • 皮肤条是横向卡片：每张 108 宽，上半是「侧栏 / 主区」两栏缩略，下半是名字 + 选中对勾。最后一张是「新建皮肤」的空槽。
  • 皮肤工作室固定 900×720：左设置 + 右预览（340），预览用色块拼一个微型壳，实时反映四色改动。
  • 四色留空表示继承：每行是「色块 + 十六进制输入 + 重置」，不用取色器弹层（避免引入第三方控件）。
  • 自定义 CSS 页签要警告：顶部一条 error 提示「写错会导致界面不可用」，底部常驻「重置为默认」出口。
  • CSS 校验会比对 token 规范：超出规范的值（如圆角 > 6）给一条 error 徽章提示，但不阻止保存——皮肤是用户自由。
  • 壁纸选择器分「内置 / 本机图片」；内置用渐变色块占位（规范禁用图片素材），本机图片走文件选择。
  • 各面适配分四个面（侧栏 / 主区 / 右栏 / 输入框），每面三选一（实心 / 半透明 / 磨砂）+ 一个全局遮罩浓度。
