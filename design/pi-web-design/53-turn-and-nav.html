HEAD 用实心；本地标签与远端分支用同色描边（跟所在泳道同色）。

这一张在定什么

  • 迷你地图是「36px 导轨 + 320px 时间线浮层」两件东西，不是一列小色块：导轨只在右缘占 36px，节点是 6px 圆点（间隔上限 50px，当前节点 8px 转 accent，标题节点用 muted 区分）；悬浮导轨才在它左侧展开 320px 的时间线浮层。
  • 浮层高度按内容、上限是转录区高度（不是通高）。通高在 8 轮以内的短会话里会在下方留下六成空白，读起来像面板坏了。
  • 编号一律对齐内容首行，不整块居中——否则单行行与两行行的编号会上下跳动，扫读时眼睛没有锚点。
  • 回答行是轮的一部分，不是独立一轮：它挂在编号列下方、带左侧 2px 从属竖线；字母 A 只在编号列出现一次（它是「跳到这条回答」的锚点）。
  • 图钉固定态不铺底色：只把图钉图标转 accent、把下边线染一档。整条上色会盖过内容。
  • 时间线浮层每一轮是「编号列 34px + 内容列」：编号是等宽 10px，下面挂一枚工具数徽章（有工具调用才出现）；内容列第一行是用户消息首行，有回复时多一行 A + 助手首行。当前轮用 6% 底 + 左侧 2px 强调条，编号转 accent。
  • 浮层顶部是「图钉」按钮（36px 高、底边发丝线 + 向下投影）：点了固定，面板跟着指针自动滚到最近一轮；不点则移开 250ms 收起。
  • 浮层里滚动条隐藏：320px 的窄栏里再切掉一条 10px 灰边会显得脏；面板本来就跟着指针滚。
  • 加载更早记录钉在列表顶部，用 ↑ + 文字两列（34px + 1fr）与轮次行对齐。
  • 转录没超出视口时整条导轨隐藏，不给一个空轨道。
  • 阶段行只占一行高度，四个相位（思考 / 等模型 / 准备工具 / 执行命令）串行滚进来，旧句上移淡出。这是为了不让人盯着一个不动的 spinner。
  • 回合写过的文件是一排芯片，带 +n −m 或「新增」徽章；数据只来自这一轮成功的 write / edit 调用，不去正文扫路径（扫会误报）。
  • 项目芯片与待办芯片都在输入框上方：项目芯片让「这条消息发给哪个工作区」在写的时候可见可改；待办芯片给进度并展开只读清单。
  • 路径动作统一一个菜单：复制路径 / 复制相对路径 / 在文件管理器显示 / 用默认应用打开 / 插入为引用。文件树、查看器、转录里的路径都调它。
  • Git ref 芯片与所在泳道同色：HEAD 实心，本地标签与远端分支用描边；这是「标签视觉上坐在它那条分支线上」的做法。
