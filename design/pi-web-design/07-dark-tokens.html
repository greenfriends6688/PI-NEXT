不新增 token 的三类 · 跟随派生 / 代码高亮 / 终端 ANSI

跟随派生

这些**没有自己的深色值**，值由别的 token 现算，深浅自动跟着变：

--surface-canvas → --n-canvas
--surface-panel → --n-panel
--diff-added → --success
--diff-added-bg → --success-soft
--diff-removed → --error
--diff-removed-bg → --error-soft
--focus-ring → --accent
--info → --accent
--info-soft → --accent-soft

规则：**能派生的绝不复制一份值**——复制出来就会在下次改色时漏掉一处。

代码高亮

复用既有 token，不引入新色相：

关键字#8a4f8f
字符串--success
数字--warning
注释--n-placeholder
函数名--accent-text

深浅各只多一个值：#8a4f8f（紫）在深色下换 #b98ac0。这是唯一一个不在 5 个色相里的例外，因为它必须与 --accent 区分开。

终端 ANSI

八色全部映射到既有 token：

black
red
green
yellow
blue
magenta

只有 magenta 与 cyan 在深色下单独提亮（#b98ac0 / #6cb2bb），其余 6 色直接复用语义 token，深浅自动跟随。

这一张在定什么

  • 一个浅色 token 名对应且只对应一个深色值，26 项全部填满，没有深色专有 token。这样切主题只需换一套变量，组件一行都不用改。
  • 深色不是取反：色阶整体抬到 #17171c → #f0f0f4，两端都不纯黑纯白。
  • 强调色在深色下要提亮（#5566d8 → #7b89e6）；--accent-on 从白翻成深色。
  • 「按下」在深色下是提亮：--accent-active 比 base 更亮（浅色里是更深）。
  • 叠色反向：浅色叠 6%/10% 黑，深色叠 6%/10% 白。
  • 语义淡底换成同色相暗调，不是把浅色淡底压暗——否则状态文字在上面会不够对比。
  • 能派生的绝不复制值：--surface-*、--diff-*、--focus-ring、--info* 都由别的 token 现算。
  • 阴影在深色下加重，否则弹层与底分不开。
  • 不新增 token 的三类：跟随派生（9 项）、代码高亮（5 项，只多 1 个紫）、终端 ANSI（8 色，只多 2 个提亮）。
