这一张在定什么

  • 文件树行高 24，比侧栏会话行（48）密一倍——它是「浏览」不是「阅读」。缩进每级 14px。
  • 改动列表钉在树顶：一条发丝分隔线之下是 git 改动文件，改动文件用 file-diff 图标 + warning 色，新增文件用 file-plus + success 色。
  • 工具栏七个动作：展开折叠 / 在文件管理器打开 / 打开终端 / 搜索 / 上传 / 刷新 / 关闭。全部 24 见方的图标按钮，默认弱化色，hover 出深色容器。
  • 查看器头给三样信息：文件名（等宽）、格式徽章、改动状态徽章；右端是视图切换（源码 / 预览）、复制、下载。
  • 冲突不自动解决：给「用磁盘版本 / 保留我的编辑」两个按钮，默认不选，让用户决定。
  • 删除必须二次确认，确认框里写明「删的是什么、有多少、能不能恢复」，并提示 Shift 可跳过。
  • 文件头有一枚 6px 的实时同步点：监听中是 success 圆点 + 4px 光晕，未监听是 --n-border 圆点；两种状态各配一句 title。它是圆点不是徽章——头部已经有一个格式徽章和一个改动徽章，再加文字徽章就成标签墙了。文件已删除的对比视图里不画它。
