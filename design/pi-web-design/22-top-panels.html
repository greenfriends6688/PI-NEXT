这一张在定什么

  • 顶栏下拉是信息型弹层：内容只读或只做一次跳转，不做复杂表单。唯一的例外是工具定义（带参数表）。
  • 子代理状态用图标 + 文字双通道：图标给颜色（accent 运行 / warning 排队 / success 完成 / error 失败 / 弱化 中止中断），文字给状态名。六态互斥。
  • 系统提示词只读：等宽、带行内注释色，页脚写明来源（agent 的 initialize 响应）。不给编辑入口——改提示词属于 agent 配置，在设置里。
  • 工具定义的参数表四列：参数 / 类型 / 必需 / 允许值或默认值。「必需」用 error 徽章，其余用中性文字。
  • 查找条悬浮在转录右上，不占布局；有结果给 3 / 7，无结果整条转 warning 色。
