角标挂在按钮外面的那层定位盒上（渲染位置与挂在按钮里完全一样）：它钉在右上角，本来就不与图标同行，放进按钮里会被 check-align.mjs 当成「图标 + 文字」判成错位。

这一张在定什么

  • 顶栏下拉是信息型弹层：内容只读或只做一次跳转，不做复杂表单。唯一的例外是工具定义（带参数表）。
  • 子代理状态用图标 + 文字双通道：图标给颜色（accent 运行 / warning 排队 / success 完成 / error 失败 / 弱化 中止中断），文字给状态名。六态互斥。
  • 系统提示词只读：等宽、带行内注释色，页脚写明来源（agent 的 initialize 响应）。不给编辑入口——改提示词属于 agent 配置，在设置里。
  • 工具定义的参数表四列：参数 / 类型 / 必需 / 允许值或默认值。「必需」用 error 徽章，其余用中性文字。
  • 查找条悬浮在转录右上，不占布局；有结果给 3 / 7，无结果整条转 warning 色。
  • MCP / 插件是顶栏两枚图标，不是聊天区常驻胶囊（用户裁定 2026-09-29）：图标取 server 与 blocks，28×28，hover 出浮窗、click 钉住。钉住态与悬浮态共用 --overlay-selected，视觉上分不出「开着」和「钉着」是故意的。
  • 浮窗数据是懒加载的：没打开过就只读扩展状态文本（零请求），打开过一次才以 /api/mcp、/api/plugins 的真实配置为准。列表项一律只读，改配置去设置分节。
  • 角标只给 MCP，数字取自状态文本里第一个数字；取不到就整个不显示——宁可没有角标，也不要一个过期的台数。
