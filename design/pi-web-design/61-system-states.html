这一张在定什么

  • 错误页分两层，样式来源不同：路由级错误带完整主题 token（可复用 --n-*）；根布局级错误不带 data-theme，必须用系统色 Canvas / CanvasText，否则自己也会崩。
  • 错误页必须给可恢复路径：一个「重试」（Next 16 里是 retry()）、一个「刷新页面」、一个「看控制台」，并显示 digest 供对照服务端日志。
  • 拖放落区分两态：可接受用强调色虚线框 + 强调淡底；拒绝用 error 虚线框 + error 淡底，并说明为什么拒绝（拖的是页面元素不是文件）。
  • 拖到输入框的落点更精确：输入框自己变虚线强调框，提示「加进这条消息」，而不是整个转录区亮起。
  • 拖放规则四条写死在画板上：图片 → 芯片；其它文件与目录 → @ 路径引用；超 20 MB 图片 → 退回路径引用（不报错）；非文件 → 拒绝态。
  • worktree 行在项目行之下、会话行之上，用 26px 的窄行 + 分支图标，右侧一个计数徽章；有未提交改动的检出给 warning 徽章。
  • 移除检出必须处理未提交改动：先提示有多少文件、给出「先提交」的建议，再给「强制移除」。不静默丢改动。
