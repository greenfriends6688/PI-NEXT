这一张在定什么

  • 本产品没有登录：登录页已从本画板删除（用户裁定，2026-09-28）。不弹登录框、不做会话令牌、不做「退出登录」设置项。
  • 目录选择的主路径是系统原生选框，不是自绘浏览器：点「选择目录」直接交给操作系统（/api/cwd/pick）。 系统选框不可用（浏览器直连 / 无显示器 / 缺 zenity）才退到自绘浏览器；用户自己取消就什么也不做，不弹二次确认。 系统对话框本身不画——那是操作系统的东西。
  • 项目信任必须解释清楚：正文写明「会读写文件、执行命令」，并给「记住这个选择」开关；不信任是 danger ghost 而不是红色填充。
  • 目录选择器的危险动作只删空目录，并把这一条写在提示里；无权限的目录整行弱化 + 「无权限」徽章。
  • 扩展请求对话框带倒计时条（3px，强调色填充），倒计时数字在标题右端。四种类型共用同一个壳，只换正文区。
  • 已响应的扩展请求收成只读回显，不再给按钮，只留「已提交 · 时间」。
  • 危险确认用 error 填充的主按钮（这是唯一允许红色填充的地方，因为动作本身不可逆），普通确认用 ghost 的 danger 文字。
  • 通知条三色 + 一个可选动作（如「重载会话」），最多 3 条、6 秒自收、鼠标停着不收。
