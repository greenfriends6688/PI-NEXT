这一张在定什么

  • 列表 + 详情两栏：列表 260px，选中项用强调淡底 + 强调色文字。列表里每一行可以带一句副标题（模型数、接口地址）。
  • 订阅登录四态：未登录 / 登录中 / 已登录（success 徽章）/ 登录失败（error 徽章 + 重试）。
  • 用量摘要是四张小卡，不画图表（图表在「用量」分节）；每张卡是「标签 / 数值 / 一行补充」。
  • 模型启用用开关行：一行一个模型，左侧开关、中间名字 + 规格副标题、右侧徽章（默认 / 可钉思考档）。
  • 成本四项分列：输入 / 输出 / 缓存读 / 缓存写，全部等宽数字。这是全应用唯一出现「缓存写」定价的地方。
  • 测试连接给原始请求回显：一行 method + path、一行状态、一段 JSON 摘要，方便排查兼容性问题。
