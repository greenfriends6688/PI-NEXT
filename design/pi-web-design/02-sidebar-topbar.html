这一张在定什么

  • 状态标记一律在右侧，左侧不放点：运行中是底边一条 1px 常亮线 + 96px 强调亮点匀速掠过（1400ms linear infinite，全系统唯一允许 linear 的动效）；未读是 N 条消息 之后一个 6px success 圆点；等你处理是同一位置一枚 warning 文字标记（待授权 / 待输入）。
  • 三者互斥，行高只有两种：空闲 48；运行中与等你处理 58。行高变化不做过渡（过渡会在列表里读成「抖动」）。
  • 取消与失败在侧栏一律不表达：那是转录里结束行该说的话，侧栏只回答「在跑 / 有结果没看 / 等你」三个问题。
  • 未读点只做 opacity：会话被查看后淡出并从布局里移除，不留占位；「N 条消息」文字本身不变色不加粗。
  • 悬浮动作只在 hover 出现：重命名与删除两个图标，默认 opacity 0；触屏下改常显。
  • 两个 pane 用分段控件切：项目 / 聊天，选中态是「更亮的底 + 加重文字」，不是强调色填充。
  • 搜索命中用强调淡底高亮，不用黄色马克笔色（那会引入第 6 个色相）。
  • 顶栏右侧动作随上下文变：会话态给历史 / 生成标题 / 子代理 / 分支 / 系统提示词 / 工具定义 / 导出 Markdown / 面板；工作区态给分支 / 工作区切换 / 在跑数徽章。
  • 在跑数与等你数并排：在跑用 accent 徽章、等你用 warning 徽章，当前工作区也挂。
  • 用户自定义分组只有四态，没有第五种：展开 / 折叠 / 拖放高亮 / 就地改名。改名不弹对话框——分组头本身就是一个 24px 输入框，Enter 提交、Esc 取消、失焦提交。分组头同时是拖放落点，与会话选中态共用 --overlay-selected。
  • 「拖到这里移出分组」是常驻落点不是菜单项：它只在拖一个已在组里的项目时出现，挂在分组列表末尾。没有它，用户想撤销一次误拖就只能再拖回去。
