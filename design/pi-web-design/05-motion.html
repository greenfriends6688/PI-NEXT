05 · 动效规格

全系统的动效在这里定完。**本画板里的动效都是真的在播**——每一格循环演示，系统开了「减少动态效果」时全部停在终态。 分帧时间轴按 2px / ms 画，只作示意；曲线与数值一律以规格表为准。

分帧时间轴 · A 整块替换 · B 重载 agent · 2px / ms只作示意

A · 整块替换（切会话 / 切标签）

200ms · 上移 8px + 淡入

t = 0ms旧内容消失；新内容 opacity 0 + translateY 8px，不可见
t = 100ms视觉中点（按 --ease 实际已走完约 87%）
t = 200ms到位：opacity 1 · translateY 0
虚线框 = 受影响区域。切会话只动转录内容，其他一律不动。

B · 重载 agent（带等待期）

120ms → 等待（时长不可预知）→ 200ms

① 0ms顶栏出 spinner；转录区仍 opacity 1
② 120ms降到 opacity 0.5，旧内容还在、不可交互
③ 等待保持 0.5，不加任何新元素
④ 完成撤 spinner，整套复用 A 组（起点是 0，不是 0.5）
等待期**不做进度条、不做假进度、不加骨架屏**——时长不可预知，假进度比不动的 0.5 更让人焦虑。
反例与禁区 · 每一条都对应一个真实会犯的错

四类转场各自的反例

  • A 整块替换：不做旧内容淡出（0ms 移除）；不做横滑；不做缩放；新旧内容任何一帧都不得同时可读；长转录不逐卡错开。
  • B 等待期：等待期不得新增任何组件，不得做进度表达，不得让输入框或左右栏跟着变暗。
  • C 弹层：不做缩放、不做从触发点放大；关闭不做退场动画（0ms 消失）；出现期间底层内容不变暗、不模糊。
  • D 展开折叠：内部内容不单独做位移动画（外层已经在变高，里层再位移会叠成「东西在飞」）。

全局禁区

  • 不弹跳：不用 spring / overshoot。
  • 不缩放文字：scale 会让字发虚。
  • 不同时动 3 个以上属性。
  • 内容类动效不超过 200ms。只有布局尺寸（侧栏折叠 / 面板宽度）允许 240ms——视觉距离大，快了读成「闪」。
  • 不做整页转场、不做骨架屏常驻、不做滚动视差。
  • prefers-reduced-motion: reduce 下一律停在终态（不是加快、不是变短）。

这一张在定什么

  1. 全系统只有四类转场 + 一类布局：整块替换（200ms）/ 带等待期的替换（120ms + ? + 200ms）/ 弹层出现（160ms）/ 展开折叠（160ms）/ 静默布局（240ms）。不在这五类里的转场不做。
  2. 曲线只有一个：cubic-bezier(.215,.61,.355,1)。两处例外是侧栏扫掠线（linear 1400ms infinite）与 spinner（linear 900ms infinite）。
  3. 十七项动效全部登记在本画板并且真的在播。画板是「看得见的规范」——旧版只有一张规格表，结果谁也不知道系统里到底有几处动画、长什么样。
  4. 轻量交互五条：悬浮进出等长 120ms；按下不做过渡；焦点环不做过渡；展开折叠 160ms；开关 120ms。
  5. 「未标注的一切不动」是全局纪律：切会话只动转录内容，顶栏 / 侧栏 / 输入框 / 滚动位置 / 折叠状态都不参与动画。
  6. 等待期不做假进度：重载 agent 的时长不可预知，界面停在 0.5 不透明度上等。
  7. 弹层关闭不做反向动画：直接移除。回缩只会拖慢下一次操作。
  8. 成组出现最多错开 3 项（40ms 一档），第 4 项起不延后。
  9. 减少动态效果时停在终态，不是「加快」也不是「变短」——前者对前庭敏感人群没用，后者会让状态读错。
