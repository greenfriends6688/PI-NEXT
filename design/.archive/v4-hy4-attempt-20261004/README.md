# PI NEXT · 设计体系 v4（浅色专业风 · 从 0-1 重画）

> **v4 = 当前目标态。** v1（`design/pi-web-design/`）是产品在用的现状，留着直到 v4 落地完；
> v2/v3 是被否掉的两稿（v2 双令牌隐患、v3 被评「视觉不好看 / 不像真实页面 / 覆盖不全」），
> 只做参考不再维护。

---

## 0 · 一句话

**一份真值（base.css）+ 两套形态（web `d-` / pwa `m-`）+ 一个主题开关。**

- **浅色专业风**为唯一基准：白底 panel、发丝边框、极轻阴影、唯一强调色 `#5566d8`（低饱和蓝紫）。
- **深色不是另一张画板**，是同一套类名下的变量覆盖（`html[data-theme="dark"]`）。
  每张画板右上角一枚开关，**一键切深**——从机制上保证两主题永不脱节。
- **画板 = 真实页面**：除 4 张参考页（令牌/动效/主题/断点）外，每张都是一个 1440×900 或
  390×844 的完整场景，填真实会话、真实路径、真实 token 数——不是组件陈列说明书。

## 1 · v3 被否的三条，v4 的对策

| v3 的问题 | v4 的对策 |
|---|---|
| 视觉不好看（近黑反色块、无品牌色、密度过紧） | 浅色专业风：白底 + 发丝边 + `#5566d8` 唯一强调色 + 两级极轻阴影 + 毛玻璃顶栏；圆角整体柔一档 |
| 不像真实页面（组件格子陈列） | 画板即页面：完整三栏/单栏场景、真实内容、可交互；组件陈列只保留在令牌/动效参考页 |
| 覆盖不全（24 张，设置挤 1 张） | **62 张**：Web 40 + PWA 18 + 跨端 4（清单见 §3） |

## 4 · 可点 demo（`assets/demo.js`）

画板**不写脚本**，只加属性：

| 属性 | 作用 |
|---|---|
| `data-demo-theme` | **一键切深/浅**（html[data-theme]；配 `data-theme-label` 自动翻转按钮文字） |
| `data-demo-tabs` / `data-demo-tab` / `data-demo-pane` / `data-demo-scope` | 页签互斥切换 |
| `data-demo-open` / `data-demo-pop` | 浮层开合（点外部/Esc 关） |
| `data-demo-drawer`（open/close/toggle）+ `data-demo-drawer-target` | 抽屉/底部面板 |
| `data-demo-scrim` | 遮罩 |
| `data-demo-list` / `data-demo-select` | 行选中互斥 |
| `data-demo-switch` | 开关 |
| `data-demo-append` / `data-demo-append-from` | 模拟发送 |
| `data-demo-stream`（cjk/char/reset） | 流式显现对照 |

**两个历史坑，引擎已修**：
1. demo.js 在 `<head>` 引入时 body 未解析 → **引擎自带 DOMContentLoaded 调度**（2026-10-04 踩过）；
2. `data-demo-scope` 必须挂在页签条与 pane 的**共同祖先**上，`check-v4.mjs` 有静态拦截。

## 6 · 落地

走 **`LANDING.md`**。触发口令：**「按 v4 设计落地」**。

产品接入（关键禁令）：`app/layout.tsx` 只加载

```ts
import "@/design/v4/base.css";
import "@/design/v4/web/tokens.css";   // 形态二选一
import "@/design/v4/web/system.css";
// PWA 形态：pwa/tokens.css + pwa/system.css —— 绝不同时加载两套
```

深色主题不需要第二套 CSS：产品在 `<html>` 上切 `data-theme` 即可。
