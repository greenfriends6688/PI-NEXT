这一张在定什么：
  • 能力一律同一种 chip（`.d-chipbtn`）：模型 / 思考强度 / 权限 / 工具与上下文 / 附件长得一样，只有图标与文字不同 —— 扫一行的成本从「逐个辨认控件」降到「读图标」。
  • 补全面板走 portal（.d-pop-float）：composer 是滚动容器宿主，浮窗挂在里面必然被裁；portal 到 body 上用 fixed 定位才是正解（这也是文档里点名的那个陷阱）。
  • 浮层左缘锚在触发 chip 上，右缘对齐输入框内侧；贴左缘的浮窗探出卡片会被 overflow-x: clip 裁掉，这是本仓翻过的车。
  • 切换模型不打断运行中的回合：浮层里明写「会排队到这一轮结束再应用」—— 不写这一句，用户会以为切了就生效，然后看到模型没变。
  • 危险档要能从框本身看出来：全部自动允许时输入框加红色发丝边，而不是只在菜单里留个红字。
  • @ 与 / 共用一块补全区：前缀即语法，文件 / 符号 / 会话 / 命令混排，按类型分组；键盘 ↑↓ ⎋ Esc 全覆盖。
  • 队列是一等公民：能排序、能「提升为 steer」插队、能移回输入框、能立即发送；暂停是显式按钮，不是藏在设置里的开关。
  • 上下文占用只在环里，点开才给明细；输入框下方不再挂第二条常驻横条。
