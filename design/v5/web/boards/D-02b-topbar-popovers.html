出现 / 消失：没有浮层、没有格式表单。没有会话或会话还没落盘时这枚钮禁用。
这一张在定什么：
  • 八枚浮层分三类：只读诊断（系统提示词 / 工具定义，入口都收在 ⋯ 菜单里，不再占顶栏图标位）、会话内切换（子代理 / 分支）、只读状态（插件）。三类的共同点是看一眼就跑 —— 一枚浮层里不放需要填表的表单。
  • 同一时刻只开一块：agents / branches / system / tools 四块共用一个「当前开着的顶栏浮窗」状态，点谁开谁、开新的关旧的。插件走另一套（悬停出窗 + 点击钉住），所以它不和前四块抢。
  • 每枚浮层都写清两件事：从哪枚钮进来、什么条件下消失。「消失条件」不许只写「点外面」—— 分支树要写「选中一条即关」，自动命名则根本没有浮层，它只有图标与提示文字的切换。
  • 数据一律懒加载：打开才开始拉，关掉不卸载；没打开过时插件只读扩展上报的状态文本，零请求。角标数字取不到就不显示，宁可没有也不要一个过期的台数。
  • 查找条不占布局：它悬浮在转录上方居中，有结果给 3 / 7，无结果整条转警告色；关闭时把焦点还给打开它的那个元素。
  • 最近会话这一格标了「已撤除」：用户 2026-10-01 裁定顶栏标题不再当下拉触发钮（切会话是侧栏的活）。画板留这一格是为了把「为什么顶栏没有它」写在纸上，而不是等下一个人再画一遍。
