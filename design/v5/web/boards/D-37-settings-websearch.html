这一张在定什么：
  • 只做免 key 的档：Bing / DuckDuckGo / Mojeek / 聚合 / 自建 SearXNG。参考项目那张 20 项的 provider 表里绝大多数要 key，照抄会立刻变成「一堆选项但都不能用」。
  • provider 链而不是单一 provider：主档失败 → 回退聚合；每档独立硬超时；聚合有软截止 （至少一家回来了就先出结果，不等被墙的那家 —— 实测国内 DuckDuckGo 要 10.5s 才失败）。
  • 失败逐条如实报：谁被风控（202 / 403）、谁超时、谁没配，写进结果与设置页； 空结果不伪装成「没有这件事」。
  • SSRF 是唯一信任边界：端点只允许 http(s)，云元数据地址一律拒绝； 本机 / 局域网要显式勾选才放行（自建实例就在 127.0.0.1 是真实用法）。
  • 改完立刻生效：工具每次调用读设置，所以这一页不需要「新会话生效」那套徽标（与记忆页不同）。
