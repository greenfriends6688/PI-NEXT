D-29 · 动效规格台 B · 容器与转场

D-31 管「一个元素自己变了」，这一张管「一块地方进来了 / 换掉了 / 走了」：浮层、抽屉、 底部面板、页签下划线、骨架、错峰、列表增删。判定口径只有一条 —— 凡是动了布局尺寸的用 --nx-dur-4，凡是整块替换的用 --nx-dur-3， 进出场用 --nx-dur-2，不许因为「想要更炫」就往后借一档。 能真点的都真点，库内没有的（抽屉 / 底部面板 / 遮罩 / 页签下划线）直接把要补的 CSS 写在帧里， 并把重播按钮置灰 —— 规格台不用别的动效冒充缺口。

③ 用 translateY(100%) 而不是 hidden：display 切走的元素没有过渡， 面板会「啪」地出现。④ 需要一个 JS 把选中页签的 offsetLeft/offsetWidth 写进 style —— 这段是几何计算，属产品代码，不进类。

这一张在定什么：
  • 时长由「动了什么」决定，不由「好不好看」决定：布局尺寸 --nx-dur-4 / 整块替换 --nx-dur-3 / 进出场 --nx-dur-2 / 颜色与焦点 --nx-dur-1。
  • 进场 ease-out，退场 ease-in；循环动效（扫掠）才允许 linear。这条来自 base.css 的注释，不许在组件里另写。
  • 骨架 → 内容不做交叉淡入：骨架整块卸、内容整块挂。交叉淡入会让两层文字叠着抖，而且永远停不下来。
  • 错峰是节奏不是属性：写内联 animation-delay，最多 3 项 × 40ms。
  • 发现一个库内接线缺口：demo.js 的浮层开关只切 hidden，而 .d-pop 的 display:block 只认 .is-open —— 所以本板的浮层在标签里自带 is-open（hidden 仍能强制关）。建议在 demo.js 里补一句 pop.classList.toggle("is-open", willOpen)，补完后板面可以删掉这个写法。
  • data-demo-motion 重启不了伪元素动画：骨架扫掠在 ::after 上，所以那一帧的重播走「重新挂载节点」。
