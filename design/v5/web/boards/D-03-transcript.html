思考 · 4 步

字阶比例与圆角都用了 --nx-r-* 这个前缀。CSS 里同名后者覆盖前者， 所以 calc(14px * 4px) 整条无效，--nx-fs-xs 退回继承值。

门禁只查「有没有定义」，不查「算不算得出来」，所以一路绿灯。

根因：--nx-r-* 同时是字阶比例与圆角

base.css 里先写了七档字阶比例（--nx-r-xs: 0.79 …）， 后面又写了圆角（--nx-r-xs: 4px …）。后者赢，于是：

base.css
--nx-r-xs: 0.79; /* 字阶比例 */ --nx-r-xs: 4px; /* 圆角 —— 后者赢 */ --nx-fs-xs: calc(var(--nx-ui) * var(--nx-r-xs)); /* → calc(14px * 4px) 无效 → 六档字阶全部退回继承值 */

影响面：六档派生字阶（xs/sm/cap/lg/title/display）全部退回继承值， 而门禁只检查令牌有没有被定义，不检查它算不算得出来 —— 所以一路绿灯。

档应该是实际
--nx-fs-xs11px继承（14px）
--nx-fs-sm12px继承（14px）
--nx-fs-title20px继承（14px）

修法：比例令牌改名 --nx-f-*，圆角保留 --nx-r-*， 并在门禁里加一条「* 右侧的比例必须无单位」。

这一张在定什么：
  • 用户气泡永远在右：右对齐 + 强调底 + 右下角小圆角，这一组形状差异是「谁说的」的唯一可靠信号。
  • 过程是竖线时间轴（`.d-steps`），首行从图标中心起画、末行到中心收笔 —— 中间连、两边断，这是竖线唯一合理的收法。
  • 默认折叠的是过程，不是结论：工具输出、思考、diff 收起，但标题行永远可见（含状态徽章与耗时），所以折叠态也能读出「做过什么、成没成」。
  • 失败必须给三件事：错在哪（行号）、怎么重试、还有别的选择（改参数 / 跳过）。只给一句「失败」等于把活推给用户。
  • 权限请求内联在转录里，不是浮在角上：它属于这一轮的语义，离开这条消息就失去上下文。
  • 未读分割用两条发丝线 + 一行说明，不要用色块；色块在这个界面里已经被「选中 / 运行中」占用了。
  • 结构化块是卡片不是消息：计划 / 待办 / 计划文档 / 已写文件各有形态，因为它们的生命周期与消息不同（消息不可编辑，卡片可重排）。
