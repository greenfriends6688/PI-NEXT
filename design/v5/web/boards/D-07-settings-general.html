这一张在定什么：
  • 设置是壳，不是页面。左边 11 个分节（通用 / 模型 / 技能 / 子代理 / 插件 / MCP / 定时任务 / 用量 / 归档 / 导入 / 手机与推送） 永远在同一个位置，宿主只有一种：弹窗（d-modal is-open › d-modal-box wide › d-modal-head › d-modal-body › d-set，⌘K 或设置入口唤起）， 背后是会话（会话顶栏 + 一段助手消息）。整页宿主已废止，帧 A 只留一帧产品早期形态作对照； 帧 B / C / D 的分节、行、文案必须一致，弹窗里也不能退化成只读预览。
  • 主题只有三档：浅色 / 深色 / 跟随系统。深色不是另一套组件，是同一批 d- 类下的变量覆盖； 画板右上角的「深色」按钮可以当场验证这一点（data-demo-theme，翻的是 html[data-theme]）。
  • 「新会话生效」写在行里，而不是写完再弹提示。自动重试、上下文预算、工具档都属于这一类： 当场改了就真的下个会话生效，面板不假装即时。模态里那行「需重载会话」也是同一个纪律的另一种表达。
  • 上下文预算画成滑块 + 精确数字：面板里存的是绝对 token 数（摘要预留 / 保留最近 / 分支摘要预留）， 滑块只是快速调整。之所以要标出「三个值都在窗口的 12% 以内」，是因为这三个值一旦填太满， 压缩本身就没有空间写摘要 —— 面板必须让人看见这件事，而不是等压缩失败。
  • 重试要写清「哪些失败不重试」。上下文超限、鉴权失败、参数错误重试一百次也是同一个结果； 只对网络失败 / 限流 / 5xx 退避重试，并且在「连续 429 会被算成账号级限流」的组合下先提示，而不是默默重试。
  • 声音与通知分开。完成声音在本机响，桌面通知可能落到手机；两者默认不同步， 否则想静音手机的人只能把电脑也静音。
  • 「回来时落在哪」给选项而不是给默认行为。恢复上次页面 / 进入工作台 / 直接打开上次会话， 三种人的日常完全不同 —— 而这一项每天都要遇到一次。
  • 皮肤工作室是第二屏，不是弹层里的一个输入框。它有自己的顶栏与四色 / 几何 / 不透明度 / 壁纸 / 自定义 CSS， 能导成 JSON；而内置的「默认」外观不是皮肤文件，所以那一格是只读的，这条限制写在格子里而不是藏起来。
