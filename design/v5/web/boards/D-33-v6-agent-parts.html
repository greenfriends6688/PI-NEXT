D-33 · V6 提案 · Agent 部件规格台

D-32 剧照里四个新件的多状态全集，每件都标了 beUI 原件（MIT）与 V6 的取舍。 四条纪律：① 任务清单的折叠头自带进度，行状态只有 done / run / 待做三态，不做第五种颜色； ② 审批卡的卡身永远中性，危险语义只落在命令代码与「拒绝」钮上； ③ 生图卡三阶段共用同一个 stage 盒，高度不变 —— 排队是骨架、显影是 nx-reveal、完成是元信息落定； ④ 导航轨的刻度长度编码距离：临近当前轮的刻度长，远的短，悬停弹预览卡。
