这一张在定什么：
  • 一个入口，三件事：命令 / 会话 / 文件都在同一块面板里，靠前缀分流（> # @），不再给搜索配二级菜单。
  • 空查询不空场：默认帧给的是「最近打开 + 快捷入口 + 保存的工作流」，用户按 ⌘K 的下一秒就能动手，不用先想搜索词。
  • 只加重命中片段（.d-cmd-hit）：整行打底色会盖住「哪几个字匹配了」，一行里三处命中也要一眼分得清。
  • 空态必须带下一步：没命中不是终点 —— 给最近搜索、给前缀说明、给「带着这个词新建会话」，并把索引进度说清楚。
  • 底部键位永远在（.d-cmd-foot）：↑↓ / ↵ / ⌘↵ / ⌫ / esc 各写一句人话，不放图标让人猜。
  • 面板是浮层不是页面：背后页面不重排、不滚走；范围页签只改结果区，标题栏与底部键位条始终不动。
