这一张在定什么：
  • 两段按「生效时机」分，不按功能树分：工具类开关（浏览器 / 搜索 / 生图 / 自动命名） 是新会话生效 —— 扩展在会话启动时加载，关掉不会把正在跑的会话里的它摘掉； 界面类开关（终端 / Git 图 / 轨迹 / 小地图）立即生效。每一段头上那枚徽标 就是这件事，不画「界面变了、行为没变」的假开关。
  • 关掉工具 = 不注册：接线在 lib/rpc-manager.ts 的 extensionFactories，与「内置子代理总开关」同一条口径 （运行时再查一次，过期调用也拦得住）。只藏按钮是另一种东西，本页不做。
  • 默认全开：这一节是「让你能关」，不是「替你决定」。默认关掉内置浏览器 会把用户正在用的能力悄悄拿走 —— 那是另一个决策，不藏在一次改版里。
  • 只存差异：{ features: { chatMinimap: false } }， 默认值以后可以改而不需要迁移旧文件。
  • 这一页不硬编码开关名：开关表是 lib/feature-toggles.ts 的 FEATURE_DESCRIPTORS（单一真值）。加一个开关 = 改那张表 + 三语文案， 页面自己会多一行 —— 这正是它和「手写一堆开关」的区别。
