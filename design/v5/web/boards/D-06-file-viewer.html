这一张在定什么：
  • 模式切换只换内容，不换位置。面包屑、滚动位置、上一行选中行留在原地；没有预览的模式也在模式位上给一句解释，而不是把预览键藏起来。
  • 源码 = 行号 + 四种语法色（.d-ln 与 tok-k/s/n/c），行号区不参与复制；顶栏写清行数与「只读」。
  • 差异默认对比上一次提交而不是 main：agent 的改动量小、看得完，要看全量再切。删除行划掉且只给状态色，不用整块红底 —— 整块底色会让长 diff 里找不到该看的那几行。
  • 预览按类型分流：Markdown 渲染（表格与代码块仍用同一套组件，不自带新样式）、图片看图（板上占位）、CSV 成表并在窄栏里横滚而不是压字。
  • 「打不开」永远带替代路径。不支持类型、超大文件、编码不对是三种不同的失败，各给各的下一步：换应用打开 / 按文本读 / 降级只读首尾 / 手工选编码 —— 绝不白屏，也绝不假装在加载。
