D-02c · 菜单合集

全应用的菜单只由一套原子拼成：行、分组标题、发丝分隔线、搜索头、脚注。 这一张先给原子表与尺寸口径，再给四个真实菜单（顶栏溢出、会话行右键、文件树右键的文件与目录两套）， 最后给选择器与动作簇（新建任务选择器、工作区切换器、路径动作簇四态、标签页总览）。 统一的是行的密度与配色，不是宽度 —— 行内菜单 230、带副标题的 300–340，宽度按内容收。

不许自造菜单项：这一页列的是产品里真实存在的全部右键/动作菜单与面板动作，项与文案都来自源码。 设计画板可以讨论某一项**要不要加**，但那是改产品范围 —— 要改先改产品， 画板跟着改，不能反过来在画板上先长出一项。
这一张在定什么：
  • 一套原子拼出全部菜单：行（8 种）、分组标题、发丝分隔线、搜索头、脚注。任何一块板要加菜单，只能从这里取件，不许现搓。
  • 八种行：普通 / 选中（图标位换对勾）/ 无图标 / 带快捷键 / 带子菜单 / 带反馈标签 / 禁用 / 危险。禁用是「点不动 + 字弱化」两档，危险是文字转红不是红底 —— 红底会把它抬成主行动。
  • 子菜单只做一级：右侧一枚 chevron，不做嵌套第二级（类型上就禁掉了）。
  • 长菜单必须带搜索头：新建任务、标签概览都带；worktree 列表的筛选框只在检出 ≥ 8 个时出现（小列表给常驻输入框是噪音）。内容区封顶后内部滚动，搜索框不随内容滚。
  • 当前项留在原位打勾，不抽到菜单顶上：抽走之后用户点了哪一行反而看不见了。置顶 / 归档这类开关态，文案跟着状态翻（置顶 ↔ 取消置顶）。
  • 危险项永远沉底并单独成组：文件树右键的最后一行、标签总览的最后一行，都是分隔线之下的单独一段。
  • 路径动作簇不是菜单：三个动作永远并排成行内按钮，不收进「⋯」—— 它挂的地方（文件树行尾、工具卡页脚）本来就是「用户已经看到路径了」，收进菜单等于把答案藏起来。四态：默认 / 已复制 / 失败多一枚徽章 / 紧凑变体三枚图标钮。
  • 三种反馈各只说一次：复制成功翻图标约 1.4 秒；系统动作成功不弹任何东西（结果在应用之外）；只有失败才多出一枚错误徽章。
  • 宽度按内容收：行内菜单 230、带副标题的 300–340。统一的是行的密度与配色，不是宽度。
