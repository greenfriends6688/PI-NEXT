这一张在定什么：
  • 地址栏是控制件，不是网页标签：.m-urlbar 顶距 52px 让开状态栏；.m-urlbox 是可点的一整条（点它出站点信息与跨站确认），不是只显示文字的输入框 —— 手机上没有「点标签页」这一步。
  • 设备视口条：.m-viewportbar 一排 .m-vp，五档与 Web 完全对齐：填满 / 手机 390 / 平板 768 / 笔记本 1024 / 桌面 1280；.m-sizebox 是实时读数。互斥高亮接 data-demo-list + data-demo-select（.m-vp.is-on）。预设默认落在「填满」—— 手机上这是唯一不用横滚的实际用法，别的四档是手动切过去的对照位。
  • 缩放条：.m-zoombar = 缩放钮 + .m-slider + 缩放钮 + 百分比徽章，滑杆拇指 26px，两颗缩放钮各 44px —— 三件事都不靠捏合手势（捏合会和页面滚动打架）。
  • 元素拾取只读：命中元素套 .m-viewbox-sel（2px 强调色描边 + 1px 偏移），下面一行小字写清「命中了什么 · 多大 · 选择器」；面板从底部升起（.m-menu-sheet），三个动作：复制选择器 / 就地问「为什么这么写」/ 在会话里改这段样式 —— 不改页面，只改我们的代码。
  • 跨站与失败各只占一行：.m-banner.warn 是常驻横幅（不接管整屏、点它出确认面板），加载失败走 .m-empty + 唯一一个动作「重试」。重试在板上用 data-demo-append 追加一块骨架屏来演示 —— 真机是整块替换，data-demo-append 只会追加，这是画板引擎的能力上限，写在这里提醒落地。
  • 命令中心是一个面板：.m-sheet（底部，max-height 78%）里依次是 .m-sheet-grab → 标题行 → .m-searchfield → 前缀分段 → .m-sheet-body 结果区 → .m-pickbar 确认条。结果行用 .m-sheet-row + .m-sheet-row-desc，副行写「什么时候 · 几条 · 什么状态」。
  • 前缀即语法：> 命令（改这一轮行为）、# 会话（接回刚才的活）、@ 文件（拖进上下文）。分段固定为全部 / 命令 / 会话 / 文件（「全部」在最前），三类结果在「全部」里按前缀分组；同一条结果在两种视图里长得一样 —— 用户不需要学第二套列表样式。
  • Git 图谱只做「看」（帧 D）：泳道顺序 + 未提交改动 + 分支关系，提交 / 推送 / rebase 一个按钮都不下放到手机；会改写历史的操作必须回桌面敲命令。泳道用现成图标与底色表达，不画 SVG。
