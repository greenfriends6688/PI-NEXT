M-06 · 文件与终端

手机上文件与终端是两个全屏页，不是桌面右栏的两块下沿。 文件树一次只显示一层：手指点文件夹比点展开三角准，缩进也会挤掉右侧的条数与操作； 层级信息改由顶栏路径 + 返回箭头承担。查看器是 inset:0 的全屏覆盖， 顶栏写完整路径（可横滚），正文自带横滚，屏幕再窄也不折行。 终端的关键是工具条：软键盘把 Esc / Ctrl-C / Tab / 方向键全吃掉， 所以底部必须有一条触控够得着的物理键排 —— 这是桌面版完全没有、手机版不能省的一行。

这一张在定什么：
  • 一屏一层，不做多级展开树：手机上点文件夹「进去」比点展开三角准，缩进还会挤掉右侧的条数与操作。层级改由顶栏路径（.m-top-title，单行省略）加返回箭头承担。文件页的滚动区就是 .m-list 本身（flex 列里的 flex:1 1 auto + min-height:0），所以它一定滚得动；分组标题 .m-group-title 直接排在列表里。
  • 选中要看得见：.m-trow.is-on 用 --nx-selected 底色 + 正文色，不用描边 —— 描边在 390 宽上会和分隔线打架。选中即进入查看器。
  • 查看器是全屏覆盖：.m-viewer 直接 inset:0 压住整页；.m-viewer-bar 顶距 50px 让开状态栏，路径用等宽小字、单行省略、超长时横向可读（完整路径在「复制」里）；.m-viewer-scroll 是唯一滚动区，代码用 .m-code + .m-code-scroll 横滚不折行 —— 折行的代码没法复制。
  • 三种看法做成三等宽分段：源码 / 差异 / 预览，默认落在第一格「源码」—— 与 Web 的顺序一致。切段只换内容区（每个 pane 自带 .m-viewer-scroll，天然各自滚动），顶栏路径与底部动作条不动。差异在手机上只读，且增删靠 .m-code-body 里的 + / − 前缀表达；不支持的二进制走帧 F 的降级卡，不拿空白面板顶替。
  • 轨迹只有一条线（帧 D）：本轮读了什么、跑了什么、写了什么全合并进 .m-steps，文件 / 终端 / 浏览器任何面板的动作都汇到这一处，不再按面板各开一份。失败步骤就地标红并保留退出码，被权限拦下的命令不静默消失。
  • 审查分两份来源（帧 E）：上面是 git diff（磁盘上的事实），下面是本轮 agent 写过的文件（会话自述）；两边都有才敢说「这一轮改了什么」。审查只读，不做 Keep / Reject，提交与丢弃留在桌面端。
  • 终端输出区自己滚：.m-term-mobile 取 flex:1 1 auto，提示符走 .m-term-prompt、成功走 .m-term-ok、失败走 .m-err；命令与输出不混排 —— 输出整体缩进一格，肉眼才能分清「敲的」和「回的」。
  • 触控下限 44px（关键约束）：.m-keybar 常驻底部，行高由 .m-key 的 min-width: 44px + 左右 10px padding 决定，但键帽高度是 --nx-ctl-sm（36px），低于 --nx-touch-min（44px）。也就是说：宽度够、纵向不够。真机落地方案必须给 .m-key 补 min-height: var(--nx-touch-min)，或把键排改成两行 —— 两者都动到 system.css，本张画板只记录需求，不自己加规则。键排横向可滚（overflow-x:auto），9 键在 390 宽上必然要滑，这是可接受的：常用四件（Ctrl-C / Esc / Tab / ↑）永远排在最左。
  • 信任也是一行开关：终端页顶部保留「已信任本目录」与开关（.m-perm + .m-switch），随手就能把目录降级回「每次问」，不必回设置。卡片在整页里需要 14px 内缩，system.css 没有「页面级带内缩容器」这类类，这里借 .m-doc-body 顶一下。
