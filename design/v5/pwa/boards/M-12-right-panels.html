入口一律是帧 A 的底部面板；打开后六块都是全屏页 —— 底部面板只用来选，不用来装正文。
这一张在定什么：
  • 入口只留一枚，不做六个常驻页签：手机底部的中线要留给输入卡与 home 手势，六格横排既是「最远的一排」也把正文挤掉一半。所以会话页顶栏右侧只放一枚 panel-right（title「右栏面板」，与桌面 D-05 / D-01 那枚同义），点开是 .m-sheet 六项列表，每行写一句现状（如「审查 · 3 个文件待看」）—— 按需开、选完即走。
  • 六块共用一层，切块不换页面：选完进入 .m-viewer 全屏层，顶部 .m-cats 横滚六项（当前项 .is-on），右侧 .m-top-btn 是 x 关闭。切换条真接线：data-demo-tabs + data-demo-tab / data-demo-pane，只在层内换内容 —— 页面、滚动位置、会话上下文都不动。六项在 390 宽上按默认间距放不下，切换条走紧凑档 .m-cats.compact 把六项收进同屏：当前项永远看得见，不依赖「自动滚到当前项」；屏再窄时仍可横滚。
  • 层内滚动区与紧凑切换条是本张新增的两个选择器：六个 pane 用 .m-panel-scroll（已写进 pwa/system.css，等价于 .m-settings 去掉顶栏占位）：唯一纵向滚动区 + 卡片 12px 节奏；切换条用 .m-cats.compact（只收横距，不动高度与描边）。底部 .m-vbar 常驻一句「切到任何一块都不换页面，只换这一层内容」。
  • 图标沿用桌面同一批名字：轨迹 history、文件 folder、终端 square-terminal、浏览器 globe、Git git-branch、审查 file-diff。图标库只有 icons.js 一份，板上不画 SVG、不用 emoji。
  • 正文不在这里重复：审查的完整形态在 M-06 帧 E、轨迹在 M-06 帧 D、文件树 / 查看器在 M-06 帧 A / B、终端在 M-06 帧 C、浏览器在 M-07 帧 A / B、Git 在 M-07 帧 D。帧 B / C / D 只画「从切换条进来」的这一层，帧 D 的对照表把六块的形态与正文位置一次排开。
  • 一致性约束不新写：轨迹仍是单例（六个面板的动作汇成一条时间线）；审查仍是两份来源（git diff + 会话自述），只读；Git 仍只做「看」，提交 / 推送 / rebase 一个按钮都不给手机。这些规矩在 M-06 / M-07 已经立过，这张只保证切换条进来的形态与它们一致。
  • 触控下限：切换条用 .m-cats.compact，库里给到 --nx-touch-min（44px）的**高与最小宽** —— 六格同屏仍放得下（6×44 + 间隙 ≈ 280 < 318），所以不需要「先记需求、落地再补」。
