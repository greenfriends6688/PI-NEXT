这一张在定什么：
  • 三个一级页，不是一个 hub：商店 / 定时 / 用量在桌面端是设置分节，在手机端各自成页 —— 它们都要「扫一眼出结论」，塞进卡片就只剩标题。
  • 商店卡片只给一个动作：右下角箭头开同一张详情面板（data-demo-drawer="toggle"），面板里先讲它要动我什么（权限逐条列出 + 单选钮），版本与要求压到最后 —— 手机上用户是「先看风险，再看功能」。
  • 分类 chip 横滚、单选：.m-cats 不换行，靠横向滚动消化分类数；选中态只有一个，别的立刻让位（data-demo-list + data-demo-select）。
  • 定时卡只回答两件事：.m-croncard-head 末位是调度徽章 + 开关，.m-cronhist 是「上次成没成」与「下次什么时候」；失败那一条用 .m-err 就地写原因，不跳详情。
  • 开关就是开关：手机上不用「编辑 → 保存」两步，.m-switch 直接生效，关闭后的历史留着（标明「已关闭 · 下周一才跑」）—— 用户要能确认「我确实关掉了」。
  • 用量三块同源：热力图（18 周 × 每天）、柱状（本周每日）、模型占比读的是同一份会话日志；图旁边永远有一行口径，否则数字会被当成账单。
  • 时间范围用三选一，不用下拉：7 天 / 30 天 / 全部 三个 .m-picktag 互斥 —— 手机上多一层下拉只为选三个值，是纯浪费。
  • 两处「看起来被裁了」的坑，已在库里修根：① box-sizing 现在是全局声明（base.css 最上面），所以 width:100% + padding 的行放进 overflow:hidden 的卡片不会再横向溢出 28px 把末列裁掉；② 滚动区 / 设置流 / 商店流这几处 flex 列容器的直接子项一律 flex: 0 0 auto，带 overflow 与 aspect-ratio 的卡片与横滚条不再被压扁（热力图行曾被压到 4px）。板面因此不再需要任何内联兜底 —— 如果你看到别处写着 style="box-sizing:border-box"，那是过期信息，删掉它。
