D-38 · V6 毛玻璃材质 · 壳面与色场

V5 的毛玻璃只在用户自己开了壁纸时才看得见（默认底是实色 --nx-canvas）； V6 把页面底换成一层色场 --nx-canvas-field，壳面在其上半透明 + blur， 开箱即玻璃。配方逐字借 deepseek-harness 的菜单材质 （blur(40px) saturate(150%) + 0.5px 发丝描边式 elevation）。 玻璃只落在壳上 —— 侧栏 / 折叠导轨 / 顶栏 / 输入框 / 浮层； 转录、卡片、右栏面板保持近实底，长正文的对比度不许跟着底图走。

§Z · 弹层不许挂 backdrop-filter反例
backdrop-filter 会让元素成为 position: fixed 后代的包含块，浮窗被裁到视口外。 所以浮层只吃 94% 不透明填充 + elevation；要挂 blur 的是壳面（侧栏 / 导轨 / 顶栏 / 抽屉）。
输入框的霜化走 ::before两件事缺一不可
position: relative（否则伪元素量到 .d-composer-wrap 的 padding 盒上）+ isolation: isolate（否则 z-index: -1 的伪元素掉进外层堆叠上下文，被壳底盖住 = blur 白挂）。 填充与模糊都放伪元素：填充留在卡片上会把「已经掺白的底」再模糊一次，玻璃被洗白。
色场是形态值，frost 是角色已进门禁
--nx-frost-blur / --nx-frost-sat 定义在 base.css（两端同值）； --nx-canvas-field / --nx-glass-shell / --nx-glass-shell-hi / --nx-elev-panel / --nx-elev-soft 在两份 tokens 里成对定义， 且每个都在 [data-theme="dark"] 里重新声明过 —— 门禁 §3c 盯着这一条。
